# HD-123 — 2026-10-31 — Главное окно без `NSToolbar`: стандартный радиус углов на macOS 26 (слово владельца по живому окну; спека `specs/2026-10-30-design-system.md` §3.1; меняет HD-115 и HD-120 в части тулбара и радиуса).

На macOS 26 окно с тулбаром получает увеличенный радиус углов, окно только с заголовком — стандартный, как у Slack и Ghostty. Замер (сборка `--build-system native`, SDK 26+, `screencapture -o -l`, Retina 2×, строки от угла до непрозрачного края): пустой `.unified` тулбар (было) — 63 px, `.unifiedCompact` — 46 px (как Chrome), без тулбара — 35 px; эталонное окно AppKit без тулбара — 35, с тулбаром — 63; Slack 35, Ghostty 36, Chrome 46. Пустой тулбар убран; светофор ставит `TrafficLights` (`MainWindow.swift`): контейнер заголовка растягивается до 52, кнопки — на x 19 (круг 12 с краем на x 20), центр y 26, системный шаг; вызывается из `viewDidLayout` и на изменение размера / вход-выход из полноэкранного режима, в полноэкранном не трогает. Геометрия как раньше (кадры кнопок совпадают с вариантом с тулбаром), тулбар 52 по-прежнему сверяется с центром светофора (`TitleBarMetrics`), safe area хостов не используется (HD-120). Двойной щелчок и перетаскивание: попадания в полосу 52 те же, что с тулбаром (кнопки светофора, `DragView`, `WindowTitleBar`). Окно «Настройки» оставлено с тулбаром (63 px): оно повторяет системные «Настройки» (категории слева, светофор над ними, у системного окна тоже тулбар) — второстепенное окно с видом системного.
