# HD-125 — 2026-10-31 — Пустой проект в сайдбаре: «+ Новый чат» и «Архив · N»; папка вместо шеврона (слово владельца; спека `specs/2026-10-30-design-system.md` §3.3, глиф `folderOpen` в `icons-v2.html`; меняет #103 (5)).

Проект, в списке которого нет чатов (их не было или все в архиве), выглядел по-разному: никогда не имевший чатов — одна папка, клик ничего видимого не делал; с чатами в архиве — три строки «Все чаты в архиве / Открыть историю ⌘Y / + Новый чат». Теперь оба случая одинаковы: развёрнутый пустой проект показывает строки как у чатов (28, отступ 32, иконка 14 на месте точки, текст `body` `text2`) — «+ Новый чат» (`+` `accentText`, как простая строка «Новая сессия» варианта B; открывает лист для этого проекта; папки нет — неактивна) и, если у проекта есть чаты в архиве, «Архив · N» (История, суженная до проекта). Клавиши только в тултипах. Клик по любому проекту сворачивает и разворачивает его (`collapsed` сохраняется как раньше), поэтому пустой проект по клику показывает эти строки. Признак развёрнутости — только иконка: открытая папка у развёрнутого, закрытая у свёрнутого; шеврон у свёрнутого убран. Рейка и фильтр «только ждущие» не меняются (строк нет). Строки решает `AppState.emptyProjectRows` по списку проекта без закреплённых чатов: проект, чьи чаты все закреплены, тоже показывает «+ Новый чат». Отвергнуто: оставить текст «Все чаты в архиве» (одна фраза-действие вместо пояснения, §3.19) и шеврон рядом с папкой (два признака одного состояния, #106).
