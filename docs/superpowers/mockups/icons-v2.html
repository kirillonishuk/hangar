Иконки v2 — один рисованный набор, тултипы, клавиши

Сейчас в приложении SF Symbols (35 случаев в enum Icon, 33 символа) + 2 логотипа агентов. Предложение: свой набор из 32 линейных иконок в одном стиле; логотипы Claude и OpenAI остаются фирменными, не перерисовываются. Шестерёнка — та же ровная симметричная из одобренного icons-sidebar.html, только на сетке 16.

сетка 16×16линия 1.5скруглённые концы и стыкибез заливок (кроме точек статуса)рамки: 1.75…14.25 × 2.75…13.25, радиус 2 (мелкие — 1)круги: центр 8,8, r 6.25линия 1.5 pt при любом размере (16 и 12)

Главные проблемы

  • Один глиф — разные действия. × (.close) закрывает вкладку и «Отключиться» от хоста; server.rack — и метка хоста, и «Проверить сервер»; arrow.clockwise — «обновить» и «Переподключиться». → новые reconnect, disconnect, checkServer.
  • Значок не про действие. «Открыть в Finder» — macwindow.on.rectangle (окно на окне, не Finder) → лицо Finder. «…» у строки «Настройки» открывает «Добавить проект», а тултип — «Ещё» → тултип «Добавить проект — ⇧⌘N». Diff-вкладка пишет текст «±», хотя есть иконка diff → иконка.
  • Одно действие — разные глифы. «Добавить проект»: + у ПРОЕКТЫ и «…» у «Настройки». pin / pin.fill: заливка нарушает правило «без заливок» → одна булавка, закреплённая — цветом textStrong.
  • Мёртвые и дубли. .files, .changes, .search нигде не используются; .changes = .diff (тот же символ). Удалить. .newTask рисует «+» и для проекта, и для вкладки → переименовать в .add; .worktree стоит и перед именем ветки → .branch.
  • Без тултипа. заголовок АРХИВ (раскрыть/свернуть), сегменты Files / Changes, обычные вкладки (нет «— ⌘1»), ▾ хостов в листе SSH (help: ""), «обновить» в окне лимитов.
  • Тултип без клавиши. «+» вкладок «Новая вкладка» (есть ⌘T), «Показать изменения» (станет ⌥⌘2). Четыре разных формата: «Новая задача ⌘N», «Лимиты подписок (⌘⇧L)», «⌘⇧L — открыть/закрыть», «Терминал ⌃`» → один: «Действие — ⌘X», собирается из Shortcut, а не литералом.
  • Запись клавиш. в тултипах и подсказках ⌘⌥I / ⌘⇧L / ⌘⇧N — порядок не как в меню macOS; надо ⌥⌘I / ⇧⌘L / ⇧⌘N (⌃⌥⇧⌘).
  • Без хоткея, а стоит. Files / Changes инспектора (⌥⌘1 / ⌥⌘2), «Открыть в Finder» (⌥⌘R), «Скопировать путь» (⌥⌘C). Конфликтов с текущими клавишами нет (⌥⌘ занят только стрелками и I).
