# HD-051 — 2026-10-23 — SIGTERM выходит как ⌘Q, без вопроса.

`signal(SIGTERM, SIG_IGN)` + `DispatchSourceSignal` на main → `NSApp.terminate`: `applicationWillTerminate` сохраняет состояние (окно debounce не теряется), останавливает сервер (сокет удаляется), снимает блокировку сна, закрывает ssh-мастеры. Подтверждение «Работают агенты» и отказ при создании worktree не применяются (`forced`, как при выходе из системы): отвечать на лист некому.
