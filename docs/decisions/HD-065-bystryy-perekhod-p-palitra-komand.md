# HD-065 — 2026-10-24 — Быстрый переход ⌘P / палитра команд ⇧⌘P, как в VS Code (§4).

По слову пользователя («как в VS Code»; первый вариант на ⌘K отменён — ⌘K снова у Ghostty, очистка экрана). Плавающая карточка 580 над окном (дочерняя `NSPanel`, фон `sheet`, радиус 12, разовое появление 120 мс, без анимации при «Уменьшить движение»); поле поиска 17, строки 36 по 14, высота списка постоянная — набор ничего не сдвигает. ⌘P: задачи всех проектов (точка статуса, имя, проект, `⎇ ветка`, хост), с первой буквы — и файлы текущей задачи; `>` первым символом — команды (пункты таблицы клавиш, кроме ⌘1…9 и фокуса сплита, с клавишей справа), стёр `>` — обратно. ⇧⌘P открывает с `>`. Та же клавиша закрывает, другая переключает. Поиск — подпоследовательность без регистра (пробелы игнорируются) со счётом: начало слова (после разделителя, camelCase, начало) и подряд идущие буквы выше, пропуски и поздний старт ниже; у файла сначала имя, потом путь; у задачи — имя, потом проект. Файлы: загруженный список инспектора (`FileTree`, до 5000, мельче — первыми); если инспектор этой задачи не загружал (скрыт) — один `git ls-files` тем же `Git.listFiles` с лимитом 5000 при первом показе ⌘P (без watcher-а; ⇧⌘P не грузит), пока идёт — строка «загрузка…»; папка не-репозиторий — без файлов. Закрыта — ничего не считается, загрузка отменяется. ↑/↓, ↩, Esc, клик; потеря фокуса закрывает. Клавиши по keyCode (работают в ru).
