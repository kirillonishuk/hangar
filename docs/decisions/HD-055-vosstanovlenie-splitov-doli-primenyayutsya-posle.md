# HD-055 — 2026-10-24 — Восстановление сплитов: доли применяются после layout `NSSplitView`.

Живая проверка: собственный layout-проход `NSSplitView` (по holding priorities) перетирал кадры из `resizeSubviews` — восстановленный сплит 0.39 открывался как 0 / всё, вложенный сплит (⌘D, затем ⌘⇧D) показывал одну панель. `RatioSplitView.layout()` после `super.layout()` заново раскладывает по `ratio`, кроме времени перетаскивания разделителя. Проверено вживую: дерево, доли, фокус, активная вкладка, TERMINAL (видимость, высота), инспектор, сайдбар (ширина, свёрнутость), рамка окна, выбранная задача, `claude --resume <id>`, Helix с тем же файлом. Не восстанавливаются (сознательно): прокрутка терминалов (Ghostty не сохраняет; claude после `--resume` сам перерисовывает разговор; сохранять текст экранов на диск — риск секретов и потеря цветов/переноса) и `cd` внутри шелла (шелл стартует в `cwd` листа: отслеживать OSC 7 нужно интеграцию шелла во внутреннем `zsh -l -i`, новое поле и обработку `GHOSTTY_ACTION_PWD` — не просили).
