# HD-054 — 2026-10-23 — Полировка области задачи (трек B).

Отступ терминала: Hangar пишет свой файл `hangar-ghostty-defaults.conf` во временной папке (`window-padding-x = 12`, `window-padding-y = 6`, `Theme.terminalPaddingX/Y` — тот же жёлобок 12, что у строки состояния и заголовка панели) и загружает его *до* файлов пользователя, поэтому их значение побеждает; файл фона (#36) по-прежнему грузится после. Конфиг Ghostty пользователя не трогается. Клавиши по keyCode: `⌃Tab` / `⌃⇧Tab` — следующая/предыдущая вкладка задачи по кругу, diff-вкладка — последней; `⌘⌥←/→/↑/↓` — фокус в соседнюю панель сплита по геометрии (`splitNeighbour`: за краем, с перекрытием по другой оси, ближайшая, затем с самой длинной общей гранью). `⌘⌥↑/↓` раньше переключали задачи (#39): без панели в этом направлении (и при фокусе в TERMINAL / diff) они так и делают. Вкладки перетаскиваются по горизонтали (как строки сайдбара: `dropIndex`, линия `accent` 2 pt); порядок — порядок массива `tabs`, сохраняется в state.json. Архивирование из меню или `⌘⇧W` показывает тост «Задача в архиве · Отменить» внизу по центру области задачи на 5 с (разовый `DispatchWorkItem`, новый тост заменяет старый); «Отменить» восстанавливает задачу и снова выбирает её, если выбранной не осталось. Архив через CLI/MCP тост не показывает. Контекстное меню строк Files / Changes: «Открыть в Helix» (не у папок и удалённых файлов), «Показать в Finder» (только локальные проекты), «Скопировать путь» (`host:path` у удалённых), «Скопировать путь от корня» (полный «…относительный путь» не влезал в меню 256). Подсказка Changes — по строке на пункт, без переноса («База: main», «⌥B — незакоммиченное»). Почему: аудит полировки (P1-8, P2-11…28) и Pane-паритет. Отвергнуто: обработка `GHOSTTY_ACTION_GOTO_SPLIT` (клавиши перехватывает монитор Hangar раньше Ghostty), горизонтальная прокрутка полосы вкладок (при нехватке места заголовки сокращаются, как раньше).
