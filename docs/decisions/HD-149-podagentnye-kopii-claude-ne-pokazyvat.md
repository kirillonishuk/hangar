# HD-149 — 2026-11-06 — Временные копии субагентов Claude Code не показывать в «Копии без чата» и не считать «агент работает в копии» (слово владельца; уточняет HD-134 (4) и (1)).

Claude Code на каждого субагента с `isolation: "worktree"` делает временную копию `<проект>/.claude/worktrees/agent-<hex>` (ветка `worktree-agent-<hex>`), на время работы блокирует её `git worktree lock` с причиной `claude agent agent-<hex> (pid … start …)` и сам убирает после. Это не копии, которые агент делает для работы пользователя, а внутренняя кухня: в «Копии без чата · N» они только шумят, а баннер «Агент работает в копии …» при cwd субагента вводит в заблуждение. Теперь такая копия не попадает ни в «Копии без чата», ни в баннер. Признак точный: путь оканчивается на `/.claude/worktrees/agent-<hex>` И (ветка `worktree-agent-<тот же hex>` ИЛИ причина блокировки `claude agent agent-<тот же hex>`); по одному имени папки не скрываем. Копия агента по работе пользователя (`.claude/worktrees/aut-1076` через `EnterWorktree`) показывается как раньше, как и чат, уже открытый на такой копии. **Отвергнуто:** скрывать всё под `.claude/worktrees/`; скрывать по префиксу `agent-` без второго признака.
