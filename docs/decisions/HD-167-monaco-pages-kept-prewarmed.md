# HD-167 — 2026-11-18 — Страницы Monaco живут всё время окна и грузятся заранее; diff не ждёт чужих загрузок инспектора (по слову владельца «открытие файла и diff подвисает»; меняет HD-080 и HD-083 в части жизни страницы).

**Было.** Страница Monaco (WKWebView, ~4–6 МБ JS) создавалась с первой файловой вкладкой и уничтожалась с последней (HD-080, HD-083); вкладка просмотра заменяет лист при каждом клике в «Файлах», так что каждый клик после закрытия последней вкладки грузил Monaco заново. Страница diff жила, пока у задачи есть вкладка diff. Diff грузился последовательно: `.diff` инспектора вставал в очередь за любой идущей загрузкой (дерево, статус от наблюдателя), потом `numstat` и `diff`, и только после них — `git show` базы и чтение файла для Monaco.

**Стало.** (1) Страница 0 редактора (`EditorHost`) не уничтожается, когда закрыта последняя файловая вкладка, — живёт, пока открыто окно; вторая страница сплита (HD-101) по-прежнему уходит с последним своим редактором. (2) Страница diff закрытой вкладки diff не уничтожается, а остаётся запасной (одна на окно) и достаётся следующей вкладке diff любой задачи; у одновременно открытых вкладок diff разных задач страницы, как раньше, свои. (3) После показа главного окна (следующий проход цикла, не блокируя первый кадр) окно в фоне грузит страницу редактора и запасную страницу diff. При смене языка интерфейса простаивающая страница на старом языке пересоздаётся (у страницы с открытыми вкладками язык обновится, когда она освободится, — как раньше). (4) Чтобы переиспользованная страница не показала прошлый файл под новым заголовком: при смене показанной модели вид прозрачен, пока страница не отрисует два кадра после команды (`MonacoPage.revealAfterPaint`); вид diff скрыт, пока страница не получила файл текущей вкладки. (5) Diff: загрузка только diff идёт рядом с загрузкой дерева/статуса по уже известным изменениям, а не в очереди за ней; у каждой загрузки, считающей diff, — номер, и результат более старой не заменяет более новый (плюс прежняя проверка пути); идущая загрузка статуса получает повторный `.diff`, чтобы diff догнал её изменения. `git show` базы и чтение файла для Monaco стартуют при открытии вкладки параллельно с `numstat`/`diff` инспектора и друг с другом — только для файла, у которого git посчитал строки и их не больше `Git.diffMaxLines` (двоичный, непосчитанный неотслеживаемый и огромный ждут вердикта git, как раньше); diff коммита — как раньше.

**Энергия.** Простаивающая страница вне окна: WebKit считает её скрытой — `requestAnimationFrame` не идёт, таймеры страницы приглушены; курсор Monaco мигает только в фокусе, а вне окна фокуса нет; у страницы нет своих таймеров (курсор — одно отложенное сообщение после движения, HD-080). Замер в изолированном DEBUG-запуске: страница редактора без вкладок — 0,03 с CPU за 30 с, страница diff — 0,00 с.

**Цена.** Два процесса WebContent постоянно (редактор и diff): ~120–170 МБ RSS каждый в замере; раньше их не было, пока не открыт файл или diff. Взамен первый файл и первый diff открываются без загрузки Monaco: в замере содержимое на экране через ≤ 0,3 с после команды, новых процессов при открытии и после закрытия всех вкладок не появляется.

**Отвергнуто:** одна страница на редактор и diff (разные режимы Monaco, свой мост и состояние — больше кода); держать страницы diff каждой задачи (процесс на задачу); показывать прошлый diff, пока грузится следующий (именно так и виден чужой файл под новым заголовком); грузить заранее страницу второго редактора сплита (редкий случай, ещё процесс).
