# HD-076 — 2026-10-25 — Вид «Сессии» (⌘Y, redesign-v1 §5).

Накрывает область сессии и скрывает правый сайдбар; выбранная сессия остаётся выбранной в модели и в `state.json` (перезапуск с открытым видом возвращает её), в сайдбаре подсвечена только строка «Сессии». Esc или ⌘Y — назад к ней; выбор любой сессии (и той же) его закрывает, прочие правки состояния — нет. Две группы: «Закрытые сессии» проекта (новые поля `HangarTask.archivedAt` и `archivedChanges` — `+N −M` против базы, замеряется перед удалением папки worktree) и разговоры Claude/Codex папки проекта и всех worktree его сессий, по дням. Действие строки: уже открыт — фокус на вкладку; есть открытая сессия этой папки — новая вкладка `--resume` в ней; сессия закрыта — её восстановление; корень проекта без сессии — новая сессия без worktree. Метка «открыт» берётся из живых вкладок, а не из скана. Удалённый проект без связи — «нет связи», скан не идёт.
