# HD-069 — 2026-10-24 — Полоса вкладок прокручивается по горизонтали (меняет «Отвергнуто: горизонтальная прокрутка полосы вкладок» из #54).

По слову пользователя: при ~23 вкладках все сжимались до иконки, активную не было видно. Теперь как в VS Code / Pane (`TabStrip`): ширина вкладки — естественная в пределах `tabMinWidth` 110 … `tabMaxWidth` 200 (иконка, обрезанный заголовок, `×` при наведении); тесной полосе общий «потолок» срезает сначала самые широкие, а ниже минимума полоса прокручивается. Прокрутка — трекпад, колесо с ⇧ и обычное вертикальное колесо (переводится в горизонталь, строка = `tabWheelLine`), через локальный монитор `scrollWheel` только над полосой (без индикатора); у обрезанных краёв — затухание `tabFadeWidth`. Активация вкладки (клик, ⌃Tab, ⌘1–9, палитра, ссылка, новая вкладка) прокручивает её в вид с наименьшим сдвигом, с запасом на затухание; другая задача — с начала. Активная вкладка: фон `selection`, линия `accent` 2 pt по верхнему краю, текст `textStrong`; остальные — `text2`; точка статуса остаётся. При переполнении справа шеврон «Все вкладки» (меню: иконка с точкой статуса, заголовок, галочка у активной); шеврон и `+` вне прокрутки, у правого края. Перетаскивание учитывает прокрутку и у края полосы прокручивает её на шаг с каждым движением. Ширины считаются по тексту (`NSFont`), не измеряются — без скачков раскладки. Отвергнуто: `ScrollView` SwiftUI (нет перевода вертикального колеса и смещения для затухания на macOS 14).
