# HD-080 — 2026-10-26 — Редактор и diff — Monaco во WKWebView (по слову пользователя; меняет HD-003 и «свой редактор — вне рамок» §1, трек M1).

Пользователь прямо попросил VS Code-подобную правку, подсветку, переходы к определению/ссылкам (LSP — трек M2), diff, лёгкость, стили Hangar и отсутствие конфликтов клавиш, и разрешил одну загрузку `monaco-editor` (MIT) из npm. Вендорено `monaco-editor@0.57.0` `min/vs` (AMD) в `Sources/HangarUI/Monaco/vs` (+ LICENSE, ThirdPartyNotices, ATTRIBUTION.md), без воркеров языковых сервисов TS/CSS/HTML/JSON, `language/`, `.d.ts` и чужих локалей (кроме ru) — 6.4 МБ; подсветка Monarch остаётся, языковые фичи даст M2. Страница грузится из бандла по схеме `hangar-editor://` (не file://), сеть закрыта: content rule list блокирует http(s)/ws(s)/ftp, CSP `connect-src 'none'`, хранилище непостоянное. Мост типизирован: JS → Swift — JSON-строка ≤ 10 МБ, `BridgeMessage.decode` проверяет типы, диапазоны и абсолютность путей; Swift → JS — `hangar.receive(cmd)` через `callAsyncJavaScript` с аргументами. Хук M2: `AppState.editorProvider` (definition/references/hover/completion, async) и `EditorCommand.markers` для диагностик. Вкладка редактора — лист `.editor` с одной страницей и моделью на файл; файлы, активный и курсоры — в `Leaf.editorFiles` (восстанавливаются), миникарта и режим diff — в `WorkspaceState`. Чтение/запись: локально — FileManager с атомарной заменой через `.<имя>.hangar-tmp` и сохранением прав; на сервере — `sh` через runner хоста (stat + cat) и stdin-запись `RemoteHosts.write` (tmp рядом, `mv`). Внешние изменения: FSEvents по папкам открытых локальных файлов (только пока вкладка видна), для удалённых — повторный stat при фокусе/показе; чистый буфер перезагружается молча, грязный — полоса конфликта; сохранение поверх изменённого на диске файла не пишет, а показывает ту же полосу. До 2 МБ правится, 2–5 МБ — только чтение, больше и бинарные — отказ с сообщением. WKWebView живёт, только пока есть лист редактора / вкладка diff задачи; таймеров нет (курсор пишется одним отложенным сообщением после движения). Diff — Monaco diff вместо прежнего списка строк (данные `DiffContent` остаются для счётчиков и заметок). Политика клавиш — таблица в DESIGN.md «Редактор: клавиши». Код Helix и настройку редактора убирает трек M3; все входы «открыть файл» (Files, ⌘P, ↩ в diff, ссылки, переход к определению) уже идут в Monaco. Отвергнуто: свой редактор на NSTextView (нет LSP-UI, многокурсорности, diff), CodeMirror (не просили).
