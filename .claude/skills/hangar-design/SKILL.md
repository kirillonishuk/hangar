# Hangar design (утверждено владельцем 30.10, решение #112)

Источник правды — `docs/superpowers/specs/2026-10-30-design-system.md` (токены §2, компоненты §3, тексты §4, главное/второстепенное §5, бывшая строка состояния §6, миграция `Theme` §7, порядок внедрения §8). Макет — `docs/superpowers/mockups/design-system-v2.html`. Ниже — сжатая выжимка; если расходится со спекой, права спека.

## Правила
1. Каждое число — токен из таблиц ниже. Нового числа нет без правки спеки (и записи в `decisions.md`, если это решение).
2. Иерархия — весом (400/600) и уровнем текста (`text0–3`), не цветом. Цвет — статусы, git, один `accent`.
3. Акцентная заливка — только у одной главной кнопки на контекст и у выбранного в фокусе.
4. Цветное слово — только то, что требует действия: «ждёт ответа», «ошибка», «на лимите». Остальное — точкой или `text3`.
5. Второстепенное (новый чат, история, настройки, ⋯) — иконкой, подпись и клавиша — в тултипе «Действие — ⌘N».
6. Тема заполняет роли; размеры от темы не зависят. Оба сайдбара — `bg1`.
7. Наведение и выбор — без анимации; ничего не сдвигается при смене состояния.
8. Одна информация — в одном месте (#106).
9. Без капса, разрядки, теней у строк и кнопок, рамок-заглушек для пустого.

## Компоненты — чек-лист
- Тулбар 52: название чата 600 + проект caption; кнопка ветки (живой HEAD, всегда) → поповер переключения; справа только при наличии: «Обновить до X», «не спать»; всегда колокольчик и инспектор.
- Сайдбар: «Проекты» → проект (папка 16) → чаты (точка, имя, справа статус-слово или ветка mono 11 `text3`); «Серверы»; подвал — иконки «Новый чат», «История», «Настройки».
- Вкладки 26 в полосе 36, активная — `hover2`; точка 6 на иконке.
- Заголовок панели 28: путь + переключатели; у редактора — язык/LSP и «Миникарта».
- Инспектор: сегмент «Файлы · Изменения N · Git · Поиск»; строки 24.
- Кнопки: главная (`accent`) — одна; обычная (`hover2`); простая (без фона); иконка 28/22; деструктивная — текст `failedText`.
- Чип 22 (вкл. — `accentText` на .15); сегмент — один вид; флажок в листах, переключатель — в настройках; поле 28, подпись над ним.
- Меню/поповер: одна реализация, `bg2`, пункт 24, выбранный `selectedFocus`.
- Лист 520: заголовок title, подписи над полями, подвал с кнопками справа, без «esc — отмена».
- Тост 32 внизу по центру; входящие 380; История — строки 32; Настройки — карточки, подпись слева + контрол справа.
- Пусто — одна фраза-действие + ≤ 2 кнопки.

## Тексты
Русский, коротко, кнопка — глагол («Создать чат»), без английских подписей, плейсхолдер — пример значения, ошибка — что случилось и что делать. Словарь: **проект**, **чат** (не «сессия»), **новый чат**, **история** (⌘Y), **отдельная копия (worktree)**, **папка проекта**, **ветка** (mono), **сервер** (не «хост»), **в архив**, **не в коммите / вся ветка**, **агент**, **вкладка**.

## Перед тем как добавить UI
1. Нужен ли элемент вообще? Не видна ли эта информация уже рядом?
2. Какой уровень важности (спека §5)? Второстепенное — иконкой.
3. Есть ли готовый компонент? Кнопки `.buttonStyle(.hangar(…))`, `IconButton`, `Chip`, `PopupButton`, `Segmented`, `Checkbox`, `CardSwitch` (`Controls.swift`), меню `PopoverMenu`, поле `inputField` (`InputField.swift`), строка карточки `CardRow`, лист `SheetKit`. Используй его, не новый.
4. Все размеры, цвета, шрифты — токены и роли; новая константа в `Theme` только если её нет в спеке, и тогда — правка спеки.
5. Текст — по словарю и правилам; ru и en в `Localizable.strings`.
6. Проверка: Navy, Dark+, Графит; ru и en; минимальная ширина окна; без сдвигов при наведении/выборе; Reduce Motion; клавиатура (Tab, Esc, ↩).
