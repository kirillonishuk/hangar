# HD-053 — 2026-10-23 — Подсветка синтаксиса в diff — встроенный лексер, без зависимости.

По слову пользователя; tree-sitter не подключён (HD-044), `shortcut:` по «Простоте». `Syntax.swift`: построчный лексер по байтам UTF-8, классы keyword / string / comment / number / type (идентификатор с заглавной) / plain. Язык — по расширению: Swift, JS/TS/TSX/JSX, Python, Go, Rust, Kotlin/Java, C/C++/ObjC, Ruby, sh/bash/zsh, JSON, YAML/TOML (ключи, строки, комментарии), CSS, HTML/XML (теги, атрибуты), SQL, Markdown (заголовки, код); прочее — без подсветки. Многострочные строки и комментарии переносят состояние между строками ханка — отдельно по старой (контекст + `-`) и новой (контекст + `+`) стороне; на каждом заголовке ханка состояние сбрасывается (неточность принята: комментарий, открытый до ханка, не виден). Без вложенности, интерполяции, regex-литералов, heredoc. Энергия: подсвечиваются только строки, которые рисует `LazyVStack`, результат кэшируется до следующей загрузки diff; строка > 2000 байт и diff > 1 МБ текста — без подсветки. Палитра — `Theme.Diff.syntax`, `DESIGN.md` «Цвета».
