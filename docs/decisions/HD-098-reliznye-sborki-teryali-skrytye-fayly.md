# HD-098 — 2026-10-28 — Релизные сборки теряли скрытые файлы shell-integration Ghostty (zsh не читал `~/.zshrc`).

Баг: `actions/upload-artifact@v4` по умолчанию не включает скрытые файлы, поэтому артефакт `ghosttykit` в CI не содержал `share/ghostty/shell-integration/zsh/.zshenv`. Ghostty ставит `ZDOTDIR` на эту папку; без `.zshenv` zsh не возвращает `ZDOTDIR` пользователя, `~/.zshrc` не читается, в `PATH` нет `~/.local/bin`, вкладки агентов падают с `zsh:1: command not found: claude` (exit 127). Затронуты все релизы, собранные в CI (включая 0.4.0); локальные сборки были в порядке. Исправление: `include-hidden-files: true` в `.github/actions/ghosttykit/action.yml`. Защита: `scripts/bundle.sh` падает, если в `Contents/Resources/ghostty/shell-integration/zsh/.zshenv` нет файла. Это единственный нужный скрытый файл (в `share` есть ещё только `man/.placeholder`). Дополнительно `scripts/verify-bundle.sh` (в CI и release.yml: на .app до DMG и на смонтированном DMG) проверяет, что все файлы `share/{ghostty,terminfo}` включая скрытые попали в бандл, что zsh с `ZDOTDIR` Ghostty читает `~/.zshrc` во временном HOME, версию и `codesign --verify --deep --strict`.
