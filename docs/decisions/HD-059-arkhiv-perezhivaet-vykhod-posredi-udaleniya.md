# HD-059 — 2026-10-24 — Архив переживает выход посреди удаления worktree (паритет с Pane, B12).

`git worktree remove` удаляет файлы по одному: выход посреди оставлял полупапку, и восстановление считало её «уже на месте». Теперь (`removeWorktreeFolder`, и для архива, и для «Удалить навсегда» с worktree) папка сначала атомарно переименовывается в соседнюю `<путь>.hangar-removing` (`mv` на той же ФС; удалённо — тот же argv через `Runner.ssh`, каждое слово в `shellQuote`), затем `git worktree prune`, надгробие удаляется в фоне (`rm -rf`). Проверка потерь (`checkWorktree`) идёт до переименования, поэтому `--force` у `worktree remove` больше не нужен. При запуске (локальные проекты) и при подключении хоста (его проекты) удаляются оставшиеся `*.hangar-removing` — только в корне worktree известных проектов и в папках их worktree-задач. Восстановление проверяет рабочий worktree (`test -e <путь>/.git && git -C <путь> rev-parse --is-inside-work-tree`), а не наличие папки: затем `prune` и `worktree add`. Папка без `.git` (висячая ссылка `.git` считается за `.git`) трогается, только если её имя — имя worktree ветки (`branchSlug`), иначе `failed`, ничего не меняется; пустая удаляется (`rmdir`), с файлами — переименовывается в `<путь>.hangar-orphan-<время>` и не удаляется (`restoredKeeping`: в UI «Папка без .git сохранена как …», в CLI/MCP — `note`); есть `.git`, но `rev-parse` не проходит — `git worktree repair <путь>` из основного репозитория и повторная проверка; не помогло — `failed("… is not a valid worktree, left in place")`, ничего не меняется (локально, удалённо и в CLI/MCP `tasks restore`, `reviveWorktree`). `removeWorktreeFolder` (архив и удаление) отказывает, если путь не связанный worktree этого проекта (`linkedWorktree`, всё через `pwd -P`): путь равен `--show-toplevel` (не подпапка), `--git-dir` ≠ `--git-common-dir`, `--git-common-dir` совпадает с таковым основной папки проекта (не чужой репозиторий), путь — не основная папка. Основная папка не разрешается (нет, `~` на сервере, нет доступа) — отказ. Символьная ссылка: проверяется и переименовывается реальная папка, сама ссылка остаётся. Удалённо — тот же скрипт через runner (каждое слово в `shellQuote`). Отвергнуто: журнал незавершённых удалений в состоянии (надгробие само им служит).
