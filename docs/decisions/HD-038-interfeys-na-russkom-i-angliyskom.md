# HD-038 — 2026-10-18 — Интерфейс на русском и английском, переключение в настройках без перезапуска.

`language = "system" | "ru" | "en"` в `~/.config/hangar/config.toml` (по умолчанию `system`: ru, если первый язык системы русский, иначе en). Строки — `Sources/HangarUI/Resources/{ru,en}.lproj/Localizable.strings` (исходный язык ru), доступ только через `enum L10n` (ключи `L10n.Key`, тест проверяет полноту обоих языков). String Catalog (`.xcstrings`) не используется: `swift build` (Swift 6.3) копирует его в бандл без компиляции, строки не находятся. Язык выбирается чтением `<lang>.lproj` напрямую (`String(localized:locale:)` язык не выбирает — только форматирование), выбор хранится в `@Observable`, поэтому SwiftUI перерисовывается сразу; меню пересобирается, полоски ошибок терминала перечитываются при `sync`. Бандл ресурсов SwiftPM копируется в `Contents/Resources/Hangar_HangarUI.bundle` (в корне `.app` ломает подпись), `L10n` ищет его там раньше `Bundle.module`. Окно настроек (`⌘,`, шестерёнка): язык, агент по умолчанию, редактор, `external_editor` (пусто — выкл.), фон терминала (применится после перезапуска). Запись — точечная правка одной строки ключа (комментарии и прочие строки не трогаются), атомарно; нет ключа — дописывается в конец корневой секции. Почему: решение пользователя. Отвергнуто: `AppleLanguages` + перезапуск; полный TOML-писатель.
