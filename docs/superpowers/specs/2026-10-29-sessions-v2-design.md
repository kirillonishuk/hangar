# «Сессии» v2 — записка к макету

Макет: `docs/superpowers/mockups/sessions-v2.html` (A — список, рекомендую; B — список + панель). Статус: на согласовании у владельца, кода нет; выбор варианта открыт.

## Почему
Слова владельца (2026-10-29): «экран очень неудобный»; «квадратики у закрытых сессий непонятные»; «как я должен понять, что тут сессии только ssh»; «выбранная таба с серваками отображается одинаково с кнопкой новой сессии».

Сейчас (`SessionsView.swift`): два несвязанных списка («Закрытые сессии» с глифом раскладки вкладок, «Разговоры» по дням), охват — текст «Проекты на devbox ▾» в строке-счётчике, выбранный сегмент агента залит `moreBg` — тем же серым, что кнопки B′ под курсором.

## Решения владельца
- «Открыть в ворктри» (продолжить беседу основной папки в новом ворктри её ветки) — **не делаем**, вместе с копированием файлов бесед в `~/.claude`.
- Архивные сессии Hangar **без бесед** (только терминалы) — **показываются строками** в группе проекта с «Восстановить».

## Поведение (вариант A)
- **Строка = беседа** Claude/Codex либо архивная сессия Hangar без бесед. Группы — по проекту в порядке сайдбара, внутри — по последней активности (у архивной сессии — время архивации); заголовков дней нет, время справа («12:40», «вчера», «21 окт.»). Группа длиннее 5 строк свёрнута до 5 + «Показать ещё N». Заголовок группы сворачивается.
- **Строка беседы:** иконка агента · название · где шла (папка — основная папка проекта, ⎇ — ворктри) и ветка моно · состояние · время. Хост — только в заголовке группы и только при охвате «Все» (без повторов, #106). Сессия Hangar, путь, число сообщений — в тултипе строки.
- **Строка архивной сессии без бесед:** иконка терминала · имя сессии · ⎇ ветка (если ворктри) · «в архиве» · время архивации. Тултип: «Сессия deploy-logs: 2 вкладки терминала, ⎇ deploy-logs. В архиве с 23 окт.» Архивная сессия, в которой есть беседы, отдельной строкой не дублируется — её беседы стоят «в архиве» и восстанавливают её.
- **Состояние словом** вместо квадратиков: «открыт» (точка статуса агента), «в архиве» (беседа архивной сессии или сама сессия), «в истории» (только в файлах агента).
- **Охват** — сегмент в шапке: «Все» (⌘Y, по умолчанию) / «Этот Mac» / хосты (иконка сервера + точка связи `done`/`idle`; больше трёх — «Ещё ▾»). Выбранный — `accent` 14 % + рамка 25 % + `accentText` (как `ModeChip`), не серая заливка. «Сессии проекта» из меню проекта = охват «Все» + имя проекта в поиске (отдельного режима нет).
- **Фильтры** — чипы под шапкой, мультивыбор, ничего не выбрано = все: Claude, Codex | Открытые, В архиве, В истории; «Сбросить» (header-action) при любом выбранном. Архивные сессии без бесед проходят только фильтр «В архиве» (агент к ним не применяется: при выбранном агенте они скрыты). Поиск — по названию, ветке, проекту, хосту, имени сессии.
- **Действия под курсором** (состояние и время прячутся, B′): открыт — «Перейти» (primary); в архиве — «Восстановить» (primary) + корзина «Удалить навсегда»; в истории — «Продолжить» (primary, как сейчас: новая вкладка в открытой сессии ворктри этой папки, иначе новая сессия основной папки; куда — в тултипе). ↩ — главное действие, ↑↓ — по строкам.
- **Состояния:** загрузка — строки этого Mac сразу, у хоста в его группе «Читаю историю на devbox…» со спиннером; повторная загрузка подменяет список целиком в конце (как сейчас, без прыжков). Таймаут/ошибка — строка в группе хоста «devbox не ответил за 20 с» + «Повторить», текст ssh в тултипе. Хост без связи при выбранном хосте — по центру «Нет связи с gpu-box» + «Подключиться»; при «Все» — строка в группе. Архивные сессии хоста без связи видны (они в `state.json`), «Восстановить» у них недоступно с причиной «Нет связи с devbox». Пусто — «Здесь появятся беседы Claude и Codex…»; ничего не найдено — «По запросу «…» ничего нет» + «Сбросить фильтры». Таймауты прежние (60 с / 20 с).

## Вариант B
Те же строки, справа панель 372 выбранной строки: где, ветка, сессия, сообщений/начата, последнее сообщение (новое: чтение хвоста файла), действия и под ними — куда продолжится беседа. Минус — две колонки на 13", повтор ветки в строке и панели, лишнее чтение файлов. Превью при желании можно дать в A тултипом.

## Края
- Одна беседа в нескольких местах: открыта — «открыт» побеждает «в архиве».
- Беседа из папки, которой больше нет (ворктри удалён руками): «Продолжить» → новая сессия в основной папке (как сейчас).
- Беседа без названия — «Без названия»; без сообщений не показывается (как сейчас).
- Охват хоста, у которого удалены все проекты, — сегмент исчезает, охват → «Все».
- Глиф раскладки вкладок (`layout`) и счётчики «N закрытых · M разговоров» в шапке удаляются: число в заголовке группы, вкладки — в тултипе.
