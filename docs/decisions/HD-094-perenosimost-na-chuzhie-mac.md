# HD-094 — 2026-10-27 — Переносимость на чужие Mac.

(1) Без Xcode / Command Line Tools `/usr/bin/git` и др. — заглушки, каждый запуск показывает диалог установки; `Runner.local` (и git grep поиска) не запускает заглушку, если каталога разработчика нет (`DEVELOPER_DIR`, `/var/db/xcode_select_link`, Xcode.app, CLT — только проверки файлов), а возвращает 127 с подсказкой `xcode-select --install`. (2) `CFBundleDevelopmentRegion` = en: при системном языке не ru/en (de, ja) системные строки AppKit падают на язык разработки — теперь английский, как и `L10n`. (3) Исчезнувший login shell (удалённый brew fish/bash) пропускается: `$SHELL`, затем `/bin/zsh`. (4) `build-ghosttykit.sh` ищет Zig в `$ZIG`, brew обеих архитектур и PATH, проверяет версию 0.15 и наличие Xcode с Metal; `bundle.sh` проверяет ресурсы Ghostty и предупреждает о Xcode < 26. Сборка остаётся arm64 (#1); универсальная — отдельное решение.
