Дополнительно

  • Строка агента показывается, только если он установлен и залогинен по подписке. Если данных нет (например, API-ключ вместо подписки) — строки нет вовсе.
  • Цветная точка у вкладки агента тоже краснеет, если его лимит исчерпан, — чтобы было видно прямо в сессии.
  • Системное уведомление один раз при пересечении 80% и при исчерпании (выключается в настройках).
  • Обновление — только по событиям агентов и при открытии поповера, без постоянного опроса.
