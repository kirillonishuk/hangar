# HD-068 — 2026-10-24 — Иконки файлов и папок в инспекторе — сторонняя тема VS Code (MIT), исключение из «своих глифов» #56.

По слову пользователя: перенести его тему VS Code «Icons» (`yusifaliyevpro.vscicons` 1.2.12, Yusif Aliyev, MIT). `icons.json` и 776 SVG (все на них ссылаются, ≈1.4 МБ) скопированы без изменений в `Sources/HangarUI/FileIcons/` (`.copy` в ресурсы SwiftPM, попадает в `Hangar_HangarUI.bundle`; ищется как строки L10n), рядом `LICENSE.txt` и `ATTRIBUTION.md`. `FileIconTheme` повторяет правила VS Code: `fileNames` (без учёта регистра) → самое длинное составное расширение (`d.ts` раньше `ts`; `.env` → `env`) → `languageIds` по карте расширений → `file`; папки — `folderNamesExpanded` → `folderNames` → `folderExpanded`/`folder`; `rootFolderNames` поддержаны, но корня в дереве нет. Тёмный/базовый набор (light-вариантов в теме нет). SVG грузится `NSImage` лениво, только для построенных строк `LazyVStack`, кэш по id иконки (не больше числа id темы), рисуется в своих цветах размером `Theme.iconSize`. Нет темы или SVG — у папки глиф `project`, у файла пустое место того же размера, без падения. Где: дерево Files, строки Changes, заголовок diff. Отвергнуто: рисовать свой набор файловых иконок (сотни форматов, а пользователь хочет именно эту тему).
