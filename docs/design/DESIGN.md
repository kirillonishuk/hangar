# Hangar — дизайн-система

Стиль A «Ghostty-native»: тёмный, плотный, без декора. Значения взяты из CSS эталонных макетов (`docs/superpowers/mockups/style-a-v2.html`, `new-task-v4.html`, `limits.html`). Размеры в макетах — px, в приложении — pt 1:1. Только тёмная тема в v1.

Терминал (цвета текста, палитра, шрифт, размер) берётся из конфига Ghostty пользователя, фон — Hangar (решение #36). Хром UI должен с ним гармонировать; по умолчанию — токены ниже. Фон терминальной области — из темы Ghostty, хром — токены ниже (решение #23).

## Решения пользователя, из которых выросла раскладка
- Одна строка заголовка на всю ширину окна; под ней сайдбар, область сессии и правый сайдбар; внизу — строка состояния окна (redesign-v1).
- Вкладки — внутри области сессии, не сверху окна (`style-a-screens.html` с верхними вкладками устарел).
- Слева в полосе вкладок — название сессии и `⎇`.
- Лист новой сессии широкий (≥ 580), подписи в одну строку, настройки — одной карточкой.
- Агент по умолчанию claude; выбора агента в листе нет, другие — через `+` во вкладках.

## Компоненты
- **Сайдбар.** Структура — в «Раскладке». Строка сессии: точка статуса всегда в жёлобке, имя, иконка worktree — в конце строки (12 pt); в рейке вместо точки в жёлобке — плитка-монограмма 22×22 по центру рейки (`railTile`, рамка `railTileBorder` 1 pt, радиус 6, текст 11.5 semibold; у выбранной — `railTileSelected`) с точкой 7 pt в углу (`icons-sidebar.html`). «…» и булавка — поверх правого края строки (при наведении/выборе; булавка — и у закреплённой), над короткой растушёвкой 16 pt цвета фона строки: имя занимает всю ширину, наведение ничего не сдвигает. ### Тултипы и клавиши
Тултип есть у каждого кликабельного элемента, формат один: «Действие — клавиша» (`L10n.help(title, Shortcut)`), без клавиши — просто действие. Символы клавиш строит `Shortcut.label` из той же таблицы, по которой сопоставляются клавиши (keyCode, любая раскладка); модификаторы в порядке меню macOS ⌃⌥⇧⌘. Литералов «⌘N» в коде нет. ## Сайдбар: свёрнутый режим
- Жёлобок фиксированный, 44 pt; строки 32 (`railRowHeight`). Маркер (точка/иконка) стоит на одном x в обоих режимах.
- Монограмма сессии: имя делится по `-`, `_`, `.`, пробелу и границе camelCase; 2+ части — две первые буквы, одна часть — одна буква.

## Правила
- Нет капса, кроме заголовков проектов в сайдбаре (и секций пикера веток).
- В листах нет переносов подписей: `white-space: nowrap`, лист ≥ 580.
- Настройки в листе — одна карточка строк, а не набор полей с подписями сверху.
- Цвет статуса — только точкой (и ореолом для waiting), не заливкой строки.
- Никаких сторонних UI-китов: системные контролы, перекрашенные под токены.
- **Курсор: рука на всём кликабельном.** `NSCursor.pointingHand` при наведении на кнопки (+ «Новая сессия», `+` у заголовков, шестерёнка, «…», переключатели сайдбаров в заголовке, счётчики строки состояния, кнопки листов и окна настроек, сегменты), строки сайдбара (сессии, проекты, архив, плитки рейки, шевроны), вкладки и их `×`, `+` полосы вкладок, полосу «↩ перезапустить» у вышедшего/упавшего листа. Один модификатор `.pointingHand()` (macOS 15+: `pointerStyle(.link)`, иначе сбалансированные `push`/`pop` с `pop` при исчезновении); в AppKit — `addCursorRect`. Поля ввода — I-beam (и инлайн-переименование внутри строки), терминал — курсор Ghostty, разделители сплитов и сайдбара — курсор изменения размера.
- Никаких строк литералами в UI: каждая видимая строка — через `L10n` (`ru` и `en` в `Resources/*.lproj/Localizable.strings`). Литералом можно только имена продуктов и команд (Claude, Codex, Helix, Shell, Hangar, `hx`, `nvim`) и символы клавиш (⌘N).
- **Окно настроек** (`⌘,`, ширина 580, фон `sheet`): одна карточка строк «подпись → значение» (подпись `text2`, ширина 164, строки 9×12, разделители `lineSheet`, радиус 8); значения — сегменты (дорожка `field`, рамка `control`, радиус 7, отступ 2; активный сегмент `control` + `textStrong`, 3×11, радиус 5). Строка «Не засыпать» (подсказка — «Не засыпать, пока агенты работают») (вкл/выкл) — сразу после «Уведомления о лимитах». Внизу — путь к `config.toml` (моно `text3`) или ошибка записи (`failed`).
  Строки «Claude Code» / «Codex»: состояние интеграции (`text2` установлена, `waiting` устарела, `failed` не установлена, `text3` Codex не найден / доступно только в собранном приложении) + кнопка `SheetButton`. Окно согласия — лист 580: «Изменить <путь>?» (путь моно), diff моно 11.5 с переносом строк (`add`/`del`, маркеры A/D, «… N строк без изменений» `text3`), высота до 360 с прокруткой, строка о копии, ошибка `failed`, «Отмена» / «Применить» (`primary`).
  Строка «MCP-сервер Hangar» (после «Codex»): две команды `claude mcp add --scope user hangar -- '<cli>' mcp` и `codex mcp add hangar -- '<cli>' mcp` (моно `small`, `text2`, с переносом, выделяемые), у каждой `SheetButton` «Скопировать» → буфер обмена и «Команда скопирована» внизу; под ними подсказка `text3` «Запустите в терминале — Hangar сам конфиги агентов не меняет». Вне собранного .app — «Доступно только в собранном приложении» (`text3`).

## Перенос в SwiftUI
Один `enum Theme` (без экземпляров) с вложенными пространствами: `Theme.Color` (токены выше как `Color`/`NSColor`), `Theme.Status` (функция `color(for: AgentState)`), `Theme.Limit` (`color(forPercent:)` с порогами 80/95), `Theme.Font` (`ui`, `uiSmall`, `mono`…), `Theme.Metric` (ширины сайдбара/инспектора, высоты полосы вкладок/строки состояния, радиусы). Пороги 80/95 — константы в одном месте, их же использует логика уведомлений. Литералы цветов и размеров во view запрещены.
