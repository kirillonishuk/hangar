# HD-136 — 2026-11-05 — Субагенты агента в сайдбаре и их журнал (задача владельца по мотивам Orca; спека `specs/2026-11-05-agent-subagents-design.md`; дополняет #95, #111, #128).

Источник строк — только хуки (документированы, #14): `PreToolUse` Agent/Task (уже был) рождает строку по `tool_use_id` с описанием, типом и промптом; **новый хук `SubagentStart`** (`hangar event subagent-run`, добавляется тихо по #95 R1 / #111) даёт `agent_id`, а значит журнал работающего; `PostToolUse` Agent (уже был, `*`) — `agentId` и `completed` / `async_launched` (фоновый); `SubagentStop` — итог. Факты из документации: у `SubagentStart` нет описания и промпта, у `SubagentStop` есть `agent_transcript_path` (`<session>/subagents/agent-<id>.jsonl`) и `last_assistant_message`; `SubagentStop` приходит и от внутренних агентов Claude с пустым типом — они не находят строки. Поля проверяются в `hangar event` и на сокете (id `[A-Za-z0-9_-]{1,128}` — из него имя файла; путь из хука не берётся, считается по id разговора листа и его cwd). Состояние — `SubagentList` на лист, в памяти: законченные живут до хода пользователя после следующего Stop (фоновый, разбудивший Claude, остаётся на этот ход), работающий передний на Stop — «прерван», выход агента — прерваны все, новый разговор — пусто, не больше 30. Сайдбар: свёрнутая по умолчанию строка «N субагентов · K работает» под чатом (не сохраняется), строки с `StatusDot` и временем в минутах без таймера. Просмотр — лист: задание (первое сообщение журнала), шаги, итог (`SubagentHandback`, иначе последнее сообщение); журнал читается при открытии и дочитывается по FSEvents одного файла только пока лист открыт. Удалённые чаты — строки из хуков, без журнала (`hangar-remote` 6 отбрасывает `subagent-run` — сопоставление по ответу инструмента, shortcut); Codex — нет аналога; CLI/MCP — не делали. Замер (DEBUG, фейковый claude с 4 субагентами, лист закрыт): `sample` 5 с — главный поток всё время в ожидании событий, потоков `hangar.filewatcher` нет; после закрытия `watching=false`. **Отвергнуто:** опрос файлов/таймер для времени (минуты при перерисовке хватает); поиск журнала по `*.meta.json` (недокументировано); путь журнала из хука (граница доверия); вложенные строки во вкладке вместо сайдбара; свой просмотрщик истории (его не было — лист проще). Лист просмотра и сплошная точка законченного заменены #139.
