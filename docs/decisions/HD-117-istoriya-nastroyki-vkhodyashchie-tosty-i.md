# HD-117 — 2026-10-30 — История, Настройки, Входящие, тосты и пустые состояния на дизайн-системе (этап 10, спека `specs/2026-10-30-design-system.md` §3.15–3.19; дополняет #107, #109, #112).

История сохраняет поведение v2 (#107: охват «Все / Этот Mac / серверы», чипы агентов и состояний, чип проекта, группы по проекту, клавиатура) — сегмент «Все · Claude · Codex» и «Все проекты ▾» макета не вводятся, меняется только вид: группа 28 `caption` 600 `text3`, строка 32, время `mono` 11, поиск 260; «Продолжить» / «Перейти» / «Восстановить» при наведении — обычные small-кнопки (§3.8), акцент остаётся у выбранного. Настройки: навигация 216, шапка 52 со светофором (унифицированный тулбар без пунктов), карточки `bg1` с рамкой `line`, строка — подпись слева и пояснение под ней (то, что было в тултипах: уведомления, редактор, формат при сохранении), контрол справа; колонка подписей фиксированной ширины удалена; у «Агента по умолчанию» и «Внешнего редактора» — пояснения, плейсхолдер редактора — пример («например, code»); языковые серверы: путь или что нужно — строкой, статус и действие справа. Входящие: заголовок «Требуют внимания», строка «проект › чат · агент», текст, повторяющий имя агента, заменяется заголовком уведомления; у первого срочного пункта — «Открыть» (главная small), если у него нет «Разрешить»; пусто — «Всё спокойно». Тост: `radius.popover`, высота 32, тень уровня 1, «×»; наведение держит тост, уход снова даёт 5 с. Пустые состояния: нет проекта — «Добавьте папку проекта, чтобы начать» + «Добавить проект»; чат не выбран — фраза + «Новый чат»; пустые списки инспектора («Нет изменений», нет коммитов, «Чат не выбран», пустая папка) — фраза `body` `text2` по центру.
