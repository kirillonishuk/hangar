# HD-126 — 2026-10-31 — Чаты без проекта (слово владельца; спека `specs/2026-10-31-free-chats-design.md`, макет `mockups/free-chats.html`; дополняет #64, #116, #119).

Чат без проекта — обычная задача Hangar, чей `projectId` — id записи `FreeChat` (как терминал сервера, #64), а не проекта; все такие чаты работают в одной папке `<папка состояния>/Chats` (пересоздаётся перед запуском агента), агент — «Агент по умолчанию». Создание — «+» секции «Чаты», ⌥⌘N, палитра, пустое окно; имя «Чат N» до первого промпта (#116). Закрыть (⌘W последней вкладки, ⇧⌘W, «В архив») — значит усыпить: агенты останавливаются, строка остаётся тусклой, клик будит с `--resume` своего разговора (#119); тоста отмены нет. «Убрать из списка…» (с подтверждением) удаляет запись, файлы разговоров агента не трогает. Порядок — закреплённые, затем последнее использование (свой промпт агента, не выбор и не пробуждение). Сайдбар: секция «Чаты» первой (≤ 7 по свежести + закреплённые, открытые, выбранный; «Все чаты (N)…»). История: охват «Чаты» по дням с поиском по тексту разговора (только эта папка; служебные блоки и инструменты не ищутся), во «Все» группа «Чаты» первая; проект вокруг папки (`~`) её разговоры не показывает. Файлы, брошенные на «Файлы» такого чата, копируются в папку (занятое имя — «имя 2.ext»), в ввод агента вставляется упоминание файла без Enter. Тулбар — «Без проекта», без кнопки ветки. CLI и MCP таких чатов не видят. В коде спящий = `archived`: перезапуск уже поднимает только незаархивированные, восстановление уже продолжает свой разговор (#119), списки «живых» уже пропускают архив; в интерфейсе слова «архив» у таких чатов нет (ни пункта меню, ни тоста, ни маркера в Истории), ⇧⌘W их усыпляет. Уточняет дизайн-систему §3.1 (кнопки ветки нет: папка не git), §3.3 (секция «Чаты» первой), §3.17 и #107 (в охвате «Чаты» группы по дню, в остальных — по проекту). Закреплённый чат без проекта не дублируется в «Закреплённых» (#106). В `~/.claude` и `~/.codex` ничего не пишется; доверие папке claude спрашивает сам. Папка общая — значит общие и разрешения «всегда разрешать» claude (`Chats/.claude/settings.local.json`), и список `/resume` внутри чата (в нём разговоры всех чатов без проекта). Брошенный файл упоминается так, как пишет поле ввода агента: claude — `@имя` или `@"имя с пробелами"`, codex — путь, в кавычках при пробелах; `"` в имени копии заменяется на `'`. Откат на сборку без этой функции стирает `freeChats` при сохранении; при следующей загрузке задачи с неизвестным `projectId`, все агенты которых работали в `Chats`, снова становятся чатами без проекта (спящими, если были закрыты), прочие не трогаются.
