# HD-083 — 2026-10-26 — Один ряд вкладок: файл — вкладка Hangar (по слову пользователя «не нужны два ряда вкладок», меняет HD-081 в части вкладки «Редактор»).

Каждый открытый файл — своя вкладка в полосе Hangar рядом с терминалами и агентами: иконка типа файла, имя, точка несохранённого и `×`; вкладки «Редактор» с рядом файлов внутри больше нет (и пункта «Редактор» в `+`). Модель: файловая вкладка — лист `editor` с одним файлом (`Leaf.editorFiles` из одного элемента и `openFile`), `WorkspaceState.openFileTab` — открыть или перейти к вкладке файла (новая — сразу за активной, как в VS Code), `Tab.preview` — вкладка просмотра: клик в Files открывает файл в ней (одна на сессию, следующий клик заменяет файл новым листом), правка, двойной клик по вкладке или файлу и любое другое открытие оставляют её (`pinTab`). Миграция state.json: лист с несколькими файлами оставляет в своей вкладке (и сплите) активный файл, остальные становятся вкладками сразу за ней с их курсорами. Под капотом один WKWebView на окно (`EditorHost`) с моделью на вкладку (`doc` — id листа — в каждом сообщении моста и команде; URI модели — путь файла, у второй вкладки того же файла (другая сессия) — `file://<doc>/путь`, так это два буфера), вкладка на экране получает вид (`EditorPane` одалживает его) и своё состояние вида; страница создаётся с первой файловой вкладкой и уничтожается с последней. ⌘W — закрыть вкладку (с вопросом о несохранённом), ⌥⌘←/→ — снова фокус сплита (переключают ⌃Tab и ⌘1–9). Статус tsserver и «Миникарта» — в строке состояния окна. `shortcut:` diff остаётся одной временной вкладкой на сессию («файл.ts ↔», курсив) со своей страницей — несколько diff-вкладок, когда попросят.
