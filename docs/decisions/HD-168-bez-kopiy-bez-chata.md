# HD-168 — 2026-11-18 — Строки «Копии без чата» в сайдбаре нет (слово владельца; заменяет HD-134 (4), HD-147 и HD-152 (1) в части «Копий без чата», HD-141 (2)).

Владелец: блок «Копии без чата · N» под проектом шумит и не нужен — в нём всплывают и наши же временные копии агентов. Убран целиком, без флага и скрытого режима: строка под проектом, её меню («Открыть чатом» с коротким именем из ветки HD-141 (2), «Удалить копию…», пункт «Скрыть от git локально…»), поиск копий, не занятых ни одним чатом, отладочная команда `spareMenu`, тексты и тесты. Своего опроса или наблюдателя у блока не было; `git worktree list` проекта остаётся — он нужен остальному (ниже). **Остаётся:** Hangar идёт за `cwd` агента и предлагает «Агент работает в копии … · Сделать чатом этой копии» (HD-134 (1), без баннера для `agent-<hex>` — HD-152 (2)); ветка чата следует git, архив и восстановление ищут копию по пути (HD-134 (2)); строка в настройках проекта «Копии внутри проекта не скрыты от git» с кнопкой «Скрыть от git локально», скрытие вложенных копий в дереве и поиске (HD-134 (3)); «Обновить путь» (HD-122); удаление собственной копии чата при архиве и удалении (HD-059, HD-132). Проверка списка копий — как и раньше: один раз при первом показе проекта (её ответ нужен настройкам проекта и поиску), при выборе чата, по `done` агента, при возврате в окно. **Отвергнуто:** прятать строку настройкой или оставлять её только для копий вне `.claude/worktrees/` (владелец: блок не нужен совсем).
