# Дизайн-система Hangar v2 — направление B «macOS-native»

Статус: **обязательна** для всего UI (утверждена 30.10, #112). Исследование и аудит — `2026-10-30-design-system-research.md`. Макеты — `docs/superpowers/mockups/design-system-v2.html` (главное окно, редактор, «Новый чат», История, Настройки, переключатель ветки, входящие; Navy и Dark+). Скилл — `.claude/skills/hangar-design/SKILL.md`.

Утверждена владельцем 30.10 (решение #112). Решения владельца: направление B (как Xcode); шрифты — системные SF Pro + SF Mono, один моно везде (редактор и терминал по умолчанию); словарь «Чат» / «Новый чат» / «История» (⌘Y); строки состояния нет. По умолчанию оркестратора (владелец не возражал): подписи инспектора по-русски; оба сайдбара одного цвета во всех темах; переключение ветки — исключение из §1 «Вне рамок» (запись в `decisions.md`); текущая ветка (живой HEAD) видна у каждого чата.

## 1. Принципы

1. **Иерархия весом и контрастом текста, не цветом.** Два веса (400, 600), четыре уровня текста. Цвет — только у статусов, git-меток и одного акцента.
2. **Главное крупно и сразу, второстепенное — иконкой.** См. §5.
3. **Одна система чисел.** Каждый размер — токен из §2; нового числа нет без правки этой спеки.
4. **Темы заполняют роли, а не размеры.** Тема — это значения ролей из §2.7, ничего больше.
5. **Ничего не мигает.** Наведение и выбор без анимации; ничего не сдвигается при смене состояния.
6. **Один экран — одно упоминание.** Правило «Без повторов» (#106) остаётся.

## 2. Токены

### 2.1 Отступы — сетка 4 pt
`space.1` 4 · `space.2` 8 · `space.3` 12 · `space.4` 16 · `space.5` 20 · `space.6` 24 · `space.8` 32. Других отступов нет. Гэп иконка↔текст — 6 (единственное исключение, оптика иконок).

### 2.2 Шрифт
SF Pro (`.system`) и SF Mono (`.monospaced`). Терминал и Monaco по умолчанию — SF Mono того же размера; пользователь может сменить шрифт (тогда оба берут его).

| Токен | pt / строка | Веса | Где |
|---|---|---|---|
| `type.title` | 15 / 20 | 600 | заголовок листа, страницы настроек, тулбара Истории |
| `type.body` | 13 / 18 | 400, 600 | строки, вкладки, меню, поля, кнопки regular, название чата в тулбаре (600) |
| `type.secondary` | 12 / 16 | 400 | подписи над полями, пути, мета, кнопки small, сегменты, чипы |
| `type.caption` | 11 / 14 | 400, 600 | заголовки секций (600), бейджи, время, подзаголовок тулбара |
| `type.mono` | 12 / 16 (или 11 / 14 рядом с caption) | 400, 600 (буквы git) | ветки, хеши, `+N −M`, пути в полях, версии |

Без капса, без разрядки, без курсива (кроме превью файла в диффе). Sentence case везде.

### 2.3 Радиусы
`radius.control` **6** — кнопки, поля, чипы, сегменты, вкладки, строки, бейджи · `radius.popover` **10** — поповеры, меню, карточки, тосты, опции листа · `radius.window` **12** — лист, окно. Внутренний элемент сегмента — 5 (радиус дорожки − паддинг 2 + 1).

### 2.5 Иконки

Цвет — `text2`, выбранное — `text0`, на акцентной заливке — `onAccent`. Логотипы агентов — свои цвета. Точка статуса 8, на вкладке 6 (с обводкой цветом фона 1.5).

### 2.6 Линии и глубина
- `line` 1 px — разделители окна (тулбар, сайдбары, вкладки, ящик, строки карточек).
- `line2` 1 px — рамки контролов, поповеров, листов, опций.
- Уровни: 0 — плоско (окно, строки, карточки, кнопки: без теней); 1 — поповер, меню, тост: `bg2` + тень `0 8 24 rgba(0,0,0,.4)`; 2 — лист: `bg2` + тень `0 20 50 rgba(0,0,0,.5)` + затемнение окна `.35`.

### 2.8 Состояния

| Состояние | Как |
|---|---|
| наведение | фон `hover`; текст/иконка → `text0`; без анимации; рука-курсор у кликабельного |
| нажатие | фон `hover2` |
| выбрано, фокус в списке | `selectedFocus` + `onAccent` (точка получает белую обводку 1.5) |
| выбрано, фокус вне | `selected`, текст `text0` |
| активная вкладка / сегмент | `hover2` + `text0` (сегмент — ещё тень `0 1 2 .3`) |
| фокус клавиатуры | кольцо `accent` 3 pt `.25` + рамка `accent` (поля всегда, прочее — только при Tab-навигации) |
| ошибка поля | рамка `failed`, текст ошибки `failedText` secondary под полем |
| неактивно | `.4`, причина — в тултипе |
| загрузка | `ProgressView` small в месте результата, без сдвига раскладки |

### 2.9 Движение
Наведение, выбор, переключение вкладок и сегментов — мгновенно. Поповеры, меню, листы — системная анимация. Сворачивание сайдбара — 180 мс, только ширина. «Ждёт ответа» — один пульс точки при появлении (0.4 с), без повтора. Reduce Motion — всё мгновенно. Других анимаций нет.

## 4. Тексты и голос

- Русский, коротко, без «пожалуйста» и восклицаний. Кнопка — глагол, что произойдёт: «Создать чат», «Переключить», «Проверить сейчас»; результат — тем же словом («Чат создан»).
- Один язык: в русском UI нет английских подписей, кроме имён (claude, codex, git, worktree в скобках, Git как название вкладки) и кода.
- Плейсхолдер — пример значения («например, fix-login-redirect»), не инструкция.
- Ошибка — что случилось и что делать, без извинений: «Не удалось создать копию: ветка hangar/x уже есть. Выберите другое имя.»
- Пустое состояние — приглашение к действию.
- Клавиши — в тултипе «Действие — ⌘N»; в подписях и строках нет.
- Числа со словами — с согласованием («1 файл», «4 файла»), даты по-русски с заглавной в заголовках групп.

Глоссарий:

| Термин | Значение | Не писать |
|---|---|---|
| **проект** | папка репозитория в Hangar | репозиторий, workspace |
| **чат** | разговор с агентами в проекте (вкладки, папка, ветка); в коде `HangarTask` | сессия, задача |
| **новый чат** | создание чата | новая сессия |
| **история** | прошлые разговоры агентов и закрытые чаты (⌘Y) | сессии |

## 8. Порядок внедрения
