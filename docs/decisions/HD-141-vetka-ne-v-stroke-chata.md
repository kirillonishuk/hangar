# HD-141 — 2026-11-05 — Ветки нет в строке чата; «Открыть чатом» даёт короткое имя (уточняет HD-114, HD-134)

**Почему.** Ветка справа в строке чата (живой HEAD, до 92, обрезка в середине) на реальных именах вроде `user/aut-1076-epik-vitrina-…` превращалась в нечитаемое «user…zhenie» и отнимала место у имени чата; при этом та же ветка всегда видна в кнопке ветки тулбара — одна информация в двух местах (HD-106). Чат, открытый из «Копии без чата» (HD-134), получал имя, равное полной ветке, — та же нечитаемая строка уже в имени.

**Решение.** (1) Справа в строке чата — только «ждёт» / «ошибка» / «на лимите» или счётчик свёрнутых подчатов (HD-128); иначе ничего, имя занимает всю ширину. Слот под «закрепить» и «⋯» при наведении остаётся постоянным — имя не сдвигается. Ветка — только в кнопке ветки тулбара (HD-114). HEAD теперь грузится только для выбранного чата (строки больше не просят его при показе); возврат в окно перезагружает HEAD только выбранного чата. (2) «Открыть чатом» называет чат коротко: часть ветки после последнего `/`; если она начинается с ключа задачи `^[A-Za-z]+-\d+` — только ключ (`user/aut-1076-epik-…` → `aut-1076`, `feat/claude-md-refactor` → `claude-md-refactor`, `main` → `main`). Копия без ветки по-прежнему не открывается чатом (кнопка неактивна).

**Отвергнуто:** короткий ключ задачи вместо ветки в строке (всё равно дублирует тулбар и отнимает ширину у имени); срезать в строке префикс `user/` (длинный хвост ветки остаётся нечитаемым).
