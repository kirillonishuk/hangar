# HD-090 — 2026-10-27 — Языковые фичи за пределами TS/JS: общий LSP-клиент (дополняет #82).

Python, Swift, Go, Rust получают те же провайдеры Monaco, что и TS: определение, ссылки (+ превью peek), hover, автодополнение (+ документация выбранного пункта через `completionItem/resolve`), ошибки, переименование (F2) и форматирование всего файла — если сервер это умеет (по `capabilities` из `initialize`). Ничего не ставится: сервер ищется по порядку — в проекте, только где его принято ставить (`.venv/bin`, `venv/bin` — для серверов Python, `node_modules/.bin` — только для pyright/basedpyright; gopls, rust-analyzer и sourcekit-lsp из папки проекта не берутся), в PATH логин-шелла (запрос один раз, `HANGAR-PATH=` из `$SHELL -l -i`), в обычных местах (`~/.local/bin`, `~/go/bin`, `~/.cargo/bin`, `/opt/homebrew/bin`, `/usr/local/bin`), последним — `xcrun --find` (только если `xcode-select -p` успешен); `/usr/bin` пропускается — его шимы на Mac без Command Line Tools открывают диалог установки. Кандидаты: Python — `pyright-langserver --stdio`, `basedpyright-langserver --stdio`, `pylsp`; Swift — `sourcekit-lsp`; Go — `gopls`; Rust — `rust-analyzer`. Доверие то же, что у tsserver из `node_modules` проекта (#82): открыть файл в репозитории — значит запустить его инструменты; поток «доверять этой папке?» для обоих — возможный следующий шаг. Сервер запускается с PATH логин-шелла (pyright нужен node, gopls — go, rust-analyzer — cargo). Один процесс на (язык, корень проекта, исполняемый файл); корень — ближайшая вверх от файла папка с маркером языка (`go.mod`/`go.work`, `Cargo.toml`, `Package.swift`, `pyproject.toml` …), не выше корня сессии, иначе корень сессии. Жизненный цикл как у tsserver: ленивый старт, `shutdown` + `exit` + EOF через 120 с после закрытия последнего файла, один перезапуск после падения (тексты — из страницы), второе падение — «… остановлен», клик по статусу — заново (и поиск сервера для этого языка и корня — тоже заново; если прежнего исполняемого файла уже нет — его файлы ищут сервер сразу и получают новый запуск или статус «нет языкового сервера»); падение после 60 с работы после `initialize` считается первым (сервер, падающий на каждом `didOpen`, не перезапускается бесконечно). Остановка не ждёт: процесс держится до конца, через 3 с — SIGTERM, ещё через 2 с — SIGKILL (так же теперь у tsserver), запись, застрявшая на сервере, который не читает stdin, освобождается его смертью. У каждого запроса таймаут (`initialize` — 30 с, остальные — 15 с; статус не висит в «запуске»), по таймауту и при отмене запроса страницей (`cancel` из Monaco) серверу уходит `$/cancelRequest`. Не найден — спокойный статус «Python — нет языкового сервера» с подсказкой, где искали (клик — искать снова), никаких модальных окон; редактор работает как раньше. Протокол: JSON-RPC 2.0, `Content-Length`-кадры в обе стороны (чтение — тот же `TsFramer` с его лимитами), ответы сопоставляются по `id`; запросы сервера отвечаются (`workspace/configuration` — null на каждый пункт, `workspace/workspaceFolders`, `client/registerCapability`, `window/workDoneProgress/create`; `workspace/applyEdit` — `applied: false`), остальные — ошибка MethodNotFound. Синхронизация: `didOpen` (правки до инициализации буферизуются), инкрементальный `didChange` из тех же правок Monaco (сервер без инкрементальной синхронизации получает весь текст из страницы после паузы 300 мс), `didClose`. Позиции LSP (с 0, UTF-16) = колонки Monaco − 1. Всё от сервера проверяется до передачи в JS: типы, диапазоны (конец не раньше начала), лимиты списков и строк, URI только `file://` без хоста; пути — внутри корня сессии/проекта (и его realpath — пути sourcekit-lsp вида `/private/tmp/…` возвращаются к пути сессии) или в папках зависимостей (`node_modules`, `site-packages`, `.cargo/registry`, `.cargo/git`, `.rustup`, `pkg/mod`, а также найденные при первом запуске сервера языка `go env GOROOT` и `xcode-select -p` — стандартная библиотека Go и SDK/тулчейны Xcode) — после realpath пути и корней, так что симлинк из проекта наружу (например, в `~/.ssh`) отклоняется (файлы зависимостей открываются только для чтения — правило #82 расширено); plain-text hover — в блоке кода; диапазон автодополнения — из `textEdit` / `InsertReplaceEdit` сервера, если он на строке курсора и содержит курсор (иначе — слово у курсора); сниппеты — только с позициями табуляции (`$1`, `${2:x}`), любые переменные (`$CLIPBOARD`, `${TM_FILENAME}`) экранируются. Переименование: новое имя теперь приходит из страницы (`name` у `rename`), правки `WorkspaceEdit` → «префикс + имя + суффикс»; задевающее другие файлы или создающее/переносящее файлы — отклоняется, как в #82. Семантическая подсветка — только у tsserver. `shortcut:` только этот Mac — у файлов SSH-проектов LSP-сервера нет (статуса тоже); добавить запуск через ssh-мастер, как у tsserver, когда попросят. Проверено вживую с `sourcekit-lsp` из Xcode (ошибки, hover, определение, ссылки, дополнение, переименование); pyright/pylsp, gopls, rust-analyzer на машине разработки не установлены — покрыты тестом с фейковым LSP-сервером.
