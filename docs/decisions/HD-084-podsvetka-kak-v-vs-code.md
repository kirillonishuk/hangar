# HD-084 — 2026-10-26 — Подсветка как в VS Code Dark+ (по слову пользователя, скриншот его VS Code).

Палитра редактора и diff по умолчанию — Dark+ на фоне Hangar; прежняя — вариант «Hangar» (Настройки → Редактор, `editor_palette = "dark-plus" | "hangar"`). Monarch для TS/JS расширен своей фабрикой токенов (`registerTokensProviderFactory` до первой модели): управляющие слова (`import`, `export`, `from`, `as`, `return` …) — `keyword.control`, ВСЕ_ЗАГЛАВНЫЕ — `constant`. Переменные / параметры / свойства / типы / функции — семантические токены tsserver (`encodedSemanticClassifications-full`, формат 2020, разовый запрос Monaco после правок, без таймеров; переменная из заглавных — `constant`). Скобки — встроенная раскраска пар Monaco (золотой, орхидея, синий) и направляющая активной пары. Радужные отступы и плашки TODO/FIXME/HACK/XXX — декорации только видимых строк, пересчёт один раз за кадр после прокрутки, правки или смены модели; ключи `editor_rainbow_indent`, `editor_todo_highlight` (по умолчанию вкл). Смена в настройках применяется к открытым страницам сразу (команда `appearance`). `shortcut:` JSX-теги не раскрашиваются отдельно (Monarch TS их не различает) — когда попросят.
