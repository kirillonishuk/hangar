# HD-118 — 2026-10-30 — Переключатель ветки: отказы и ошибки git — в самом поповере, не тостом (этап 8b дизайн-системы, спека `specs/2026-10-30-design-system.md` §3.2; дополняет #114).

Отказ или ошибка git показываются текстом внизу открытого поповера: пользователь видит причину рядом со списком и может сразу выбрать другую ветку или имя; поповер закрывается только после успешного `switch` / `switch -c`. Новая ветка — шаг в том же поповере (имя в поле поиска), всегда от текущего HEAD. Переключатель — один на чат (`BranchModel.switchers`): идущее действие переживает закрытие поповера, результат при закрытом — тост. Правила безопасности #114 не меняются. `PopoverMenu` получил для этого пункт, который не закрывает меню (`keepsOpen`), строку под списком (`PopoverMenuNote`), смену плейсхолдера и шаг назад по Esc; колонки галочек и иконок, раз появившись, держатся, пока меню открыто (ввод не сдвигает имена), и меню может отключить отдельную колонку галочек.
