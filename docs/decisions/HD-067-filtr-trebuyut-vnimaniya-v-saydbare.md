# HD-067 — 2026-10-24 — Фильтр «Требуют внимания» в сайдбаре (лёгкая версия Attention inbox Pane).

Точка-переключатель в заголовке «Проекты» (серая на hover, цвета `waiting` и видна всегда, пока включено), `⌥⌘F` по keyCode, состояние — `attentionOnly` в state.json. Включён: задачи со статусом waiting/failed (как точка задачи, с учётом лимитов), под своими проектами; закреплённые — тоже под проектом (секция «Закреплённые» скрыта, иначе задача видна дважды или не там); свёрнутый проект остаётся свёрнутым (клик по проекту делает то же, что всегда); проекты без таких задач скрыты; пусто — строка «Никто не ждёт». Перетаскивание выключено: отфильтрованный список — не настоящий порядок. `done` не входит (просили waiting/failed). ⇧⌘[/] по-прежнему ходят по всем задачам.
