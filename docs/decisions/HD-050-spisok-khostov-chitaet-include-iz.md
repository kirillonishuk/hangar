# HD-050 — 2026-10-23 — Список хостов читает `Include` из `~/.ssh/config`.

Как OpenSSH: файл подставляется на месте строки, относительные пути — от `~/.ssh` (для `HANGAR_SSH_CONFIG` — от папки фикстуры), `~` раскрывается, glob(3) (`*`, `?`, результат отсортирован), несколько путей и `"…"` в одной строке, вложенность до 16. `Include` внутри `Match` пропускается (условный), `Match` во вложенном файле не действует на родителя. Каждый файл читается один раз (циклы), всего не больше 1 MiB: файл, переходящий лимит, и всё после него пропускаются. Только чтение. Токены `%…` и `${VAR}` не раскрываются (shortcut).
