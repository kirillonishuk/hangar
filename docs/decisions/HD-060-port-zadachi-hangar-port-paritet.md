# HD-060 — 2026-10-24 — Порт задачи `HANGAR_PORT` (паритет с `PANE_PORT`).

Параллельные worktree запускают dev-серверы без конфликта: `vite --port $HANGAR_PORT`. Порт выводится из id задачи (FNV-1a по байтам UUID, не `hashValue` — тот меняется между запусками) в диапазон 41000–48999. Занят другой задачей — берётся следующий свободный (по кругу); проверяются все задачи, а не только задачи проекта (строже, чем нужно, так же просто). Порт назначается при `addTask` и хранится в `HangarTask.port`; задачам из старого state.json он назначается при загрузке. Вкладки и нижний терминал задачи получают его в env локально (`LaunchSpec.env`) и на сервере (позиционный аргумент лаунчера, `export` в панели tmux и без tmux). Меню задачи: «Порт: 41234 (копировать)» кладёт номер в буфер. Отвергнуто: проверка занятости порта в системе при создании (dev-сервер ещё не запущен, результат случаен).
