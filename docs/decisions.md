# Журнал решений

Формат: дата — решение. **Почему.** **Отвергнуто.** Решённое не переоткрывается без новой информации; новое решение — новая запись (старую пометить «заменено #N»).

1. **2026-10-18 — Только нативный Swift для macOS (AppKit + SwiftUI), macOS 14+, Apple Silicon.** Почему: энергопотребление и простота против Electron-Pane. Отвергнуто: Electron (как Pane), кроссплатформенность.
2. **2026-10-18 — Терминал — полный embed GhosttyKit (xcframework, собранный из закреплённого коммита).** Почему: рендер и поведение как в Ghostty без своей реализации. Отвергнуто: libghostty-vt + свой рендер (много работы), управление Ghostty.app снаружи (нет контроля над вкладками и статусами).
3. **2026-10-18 — Редактор — Helix (опц. Neovim) во вкладке терминала.** Почему: LSP и правка есть готовые. Отвергнуто: свой редактор (вне рамок), внешний редактор (уход из окна).
4. **2026-10-18 — Структура проект → задача → вкладки; worktree у задачи опционален.** Почему: так пользователь работает. Отвергнуто: обязательный worktree на задачу (как в Pane).
5. **2026-10-18 — Базовая ветка по умолчанию из `origin/HEAD`, пикер с поиском (remote, затем local), последний выбор запоминается; `git fetch` перед созданием worktree.** Почему: worktree от свежей удалённой ветки. Отвергнуто: от текущей локальной ветки без fetch.
6. **2026-10-18 — Git-панель только для просмотра (Files, Changes, diff).** Почему: git-действия делаются в терминале/агентом. Отвергнуто: stage/commit/push/PR в v1.
7. **2026-10-18 — CLI `hangar` и MCP-сервер (`hangar mcp`) — в v1.** Почему: агенты должны управлять приложением сразу. Отвергнуто: отложить на v2.
8. **2026-10-18 — Визуальный стиль A «Ghostty-native»; сайдбар на всю высоту, вкладки внутри области задачи; название задачи слева от вкладок.** Почему: выбор пользователя по макетам (сайдбар главный). Отвергнуто: вкладки сверху окна (`style-a-screens.html`), «только вкладки» без названия.
9. **2026-10-18 — Агент по умолчанию claude, меняется в настройках; в листе новой задачи выбора агента нет.** Почему: меньше шагов; другие агенты — через `+`. Отвергнуто: чипы выбора агента в листе.
10. **2026-10-18 — Лист новой задачи шириной ≥ 580, настройки одной карточкой, без капса и переносов подписей.** Почему: отзыв пользователя на v1–v3. Отвергнуто: узкий лист 400 с подписями сверху.
11. **2026-10-18 — Восстановление сессии: все задачи и вкладки; claude → `claude --resume <id>`, codex → `codex resume <id>` / `--last`.** Почему: требование пользователя. Отвергнуто: переживание процессов после выхода (сложно, не нужно).
12. **2026-10-18 — Лимиты Claude: `statusLine` = `hangar statusline` (читает `rate_limits` из stdin, пересылает в сокет, вызывает исходную статус-лайн пользователя) + hook `StopFailure` matcher `rate_limit`.** Почему: документированные источники. Отвергнуто: недокументированный OAuth usage endpoint.
13. **2026-10-18 — Лимиты Codex: короткоживущий `codex app-server` → `account/rateLimits/read` (по открытию поповера, ↻, концу хода, не чаще раза в минуту); запасной — `token_count` в свежем rollout.** Почему: без постоянного процесса и опроса. Отвергнуто: `/wham/usage`, постоянный опрос.
14. **2026-10-18 — Только документированные интерфейсы агентов.** Почему: недокументированное ломается без предупреждения. Отвергнуто: приватные endpoint'ы, парсинг внутренних файлов как основной путь.
15. **2026-10-18 — Изменения в `~/.claude`, `~/.codex`, конфиге Ghostty — только с согласия, с показом diff и откатом.** Почему: это файлы пользователя. Отвергнуто: молчаливая установка hooks.
16. **2026-10-18 — ponytail — только как принципы в `AGENTS.md`; плагин не ставим.** Почему: экономия токенов без lifecycle-hooks (требуют node). Отвергнуто: установка плагина/хуков.
17. **2026-10-18 — Название приложения Hangar, CLI `hangar`.**
18. **2026-10-18 — Блокировка сна только пока есть вкладки в `working` (+2 мин), `IOPMAssertion` без root; вкл/выкл в настройках и ☕ в сайдбаре.** Почему: Mac не должен спать во время работы агентов, но и не держать бодрствование «просто открытым окном». Отвергнуто: закрытая крышка через `pmset disablesleep` (root, перегрев).
19. **2026-10-18 — SSH-проекты — этап 6; абстракция `Exec` с этапа 1.** Почему: сначала локальное, но без переделки архитектуры. Отвергнуто: SSH в первой версии; свой демон на сервере.
20. **2026-10-18 — Удалённые вкладки в tmux; при подключении Hangar проверяет сервер и предлагает установить недостающее (git, tmux, claude, codex, hx, `hangar-remote`) с подтверждением.** Почему: требование пользователя — «всё как локально»; агенты переживают обрыв и сон Mac. Отвергнуто: молчаливая установка; работа без tmux как основной режим.
21. **2026-10-18 — Статусы с сервера — проброс сокета `ssh -R` + POSIX-скрипт `hangar-remote`.** Почему: не нужно собирать Swift под Linux. Отвергнуто: Swift-бинарник на сервере, опрос сервера.
22. **2026-10-18 — Модули `Usage` (лимиты), `Power` (сон), `Exec` (локально/SSH) — отдельные.** Почему: одна ответственность на модуль.
23. **2026-10-18 — Значения по умолчанию по мелким вопросам (меняются по слову пользователя):** сайдбар 220, ширина перетаскиванием 180–320; diff только unified в v1 (split убран с макета); фон терминальной области — из темы Ghostty, хром — токены `DESIGN.md`.
