# HD-139 — 2026-11-05 — Просмотр субагента — немодальный вид в инспекторе; законченные субагенты — тихой точкой (задача владельца; меняет #136 в части листа и точки; спека `specs/2026-11-05-agent-subagents-design.md` §4–5).

Лист мешал работать рядом с журналом. Теперь клик по строке субагента показывает в инспекторе вид «Субагент» вместо его содержимого (шапка высотой с сегмент: «Субагент» и «×»): выбирает чат субагента, показывает скрытый инспектор; другая строка переключает вид. Закрывают «×», Esc (фокус в инспекторе, ни у чего, или сразу после клика по строке — пока клавиша не ушла в терминал: Esc терминала прерывает агента и не перехватывается), показ сегмента (⌥⌘1/2/3), другой чат, исчезнувшая строка. Энергия: журнал смотрится только пока вид на экране — инспектор показан, «Сессии» не поверх, окно видно (`AppState.syncSubagentPanel` из `InspectorWatch.update`); скрыт — поток FSEvents остановлен, показан снова — дописанное дочитывается один раз. Удалённые — тот же вид с заданием и итогом из хуков. Точка законченного субагента — «готово, просмотрено» (полое кольцо цвета done, #135), а не сплошная «новый результат»: итог субагента читает оркестратор, внимания пользователя он не требует; работает / прерван — как были. Замер (DEBUG, фейковый claude с 3 субагентами, один пишет шаг раз в 4 с): вид открыт — `watching=true`, шаги приходят; ⌥⌘I скрыл — `watching=false`, число шагов не растёт 5 с; показал — дочитано и `watching=true`; Esc сразу после клика, ⌥⌘1, другой чат — закрыт, `watching=false`. **Отвергнуто:** отдельная плавающая панель/окно (второе место для того же, свои правила фокуса и видимости); боковая панель рядом с инспектором (ещё одна колонка в узком окне); Esc всегда (отнимал бы Esc у агента в терминале).
