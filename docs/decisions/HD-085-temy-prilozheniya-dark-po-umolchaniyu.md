# HD-085 — 2026-10-26 — Темы приложения: Dark+ по умолчанию, Графит и Hangar Navy (по слову пользователя, макет `themes-v1.html`, коммит 41b2ec7; меняет палитру HD-036).

Цветовые токены `Theme` больше не константы: значения — `ThemePalette` на тему (имена и значения из таблиц макета, с AA-правками `text2`, кнопкой Navy `#2a6fd6`, жёлтым «ждёт» и тёмным текстом основной кнопки в Графите), текущая тема — `@Observable`-держатель, токены — вычисляемые свойства: SwiftUI перерисовывается сам, AppKit-части (слои, подписи, окна, разделители) слушают `hangarThemeDidChange`. Размеры и отступы статические, раскладка не меняется. Конфиг: `theme = "dark-plus" | "graphite" | "navy"`, по умолчанию `dark-plus` — и для существующих пользователей (их выбор). Терминал: фон и 16 цветов ANSI темы — в `hangar-ghostty-defaults-<pid>.conf` до конфига пользователя и только если его конфиг (или Ghostty-тема) своих не задаёт: тема Ghostty накладывается под всеми загруженными файлами, поэтому Hangar сравнивает конфиг пользователя с умолчаниями Ghostty (`ghostty_config_get`). «Фон терминала: как тема / из Ghostty» заменяет `terminal_background = "hangar" | "theme"`: `"hangar"` (как тема) по-прежнему перекрывает фон пользователя (HD-036); прежнее `"theme"` читается как `"ghostty"` и переписывается при следующем сохранении. Смена темы и фона живая для интерфейса и новых терминалов (`ghostty_app_update_config`); открытые терминалы сохраняют прежний фон: `ghostty_surface_update_config` заново накладывает Ghostty-тему пользователя поверх фона Hangar (shortcut в коде) — неверно, см. HD-087; Monaco получает темы и CSS-переменные в сообщении `appearance` (`defineTheme` + `setTheme`, без перезагрузки). Синтаксис редактора — Dark+ во всех темах. Отвергнуто: вариант D «Dark Modern» (решение пользователя); пересоздание дерева через `.id()` (сбрасывает состояние); динамические `NSColor` (SwiftUI не узнаёт о смене). Там же (по слову пользователя): окно настроек — категории слева, страницы карточками справа (DESIGN «Окно настроек»); строка ☕ «Не засыпать» убрана из низа сайдбара и рейки — настройка в Настройки → Уведомления, а пока блокировка сна держится, в строке состояния видна ☕ с подсказкой; поведение и `keep_awake` не менялись.
