# HD-109 — 2026-10-29 — Одна страница «Оформление»: тема оформления несёт тему редактора; фон терминала — всегда от темы; окно настроек шире (меняет HD-108 (1), (5) и HD-036/HD-085 в части фона терминала).

Слово владельца: «оформление и редактор объединить, чтобы с темой шла тема для редактора — как одно целое, но и редактор можно отдельно изменить под себя»; фон терминала всегда из темы; окно настроек по умолчанию ≈ 970 × 600. (1) `editor_palette = "theme"` — «Как у темы», по умолчанию и при отсутствии ключа: Dark+ → VS Code Dark Modern, Navy → Hangar, **Графит → VS Code Dark+** — его цвета редактора (фон, номера, текущая строка, выделение, курсор `accent`) и так берутся из темы оформления, то есть из тёплых серых Графита, а синтаксис — Dark+; отдельная палитра не нужна. `HangarConfig.editorBase` — встроенная тема, чьи цвета показывает редактор (пара темы / выбранная / основа «Своей»). Смена темы при «Как у темы» сразу перекрашивает открытые редакторы и diff (`setTheme` → `onEditorAppearance`). (2) Явные `dark-modern` / `dark-plus` / `hangar` из v0.7.0 остаются допустимыми и выглядят как прежде в любой теме; в настройках это «Своя» на этой основе без изменений; изменение цвета делает `custom` с этой основой. `custom` работает как в HD-108. `editor_custom_base` — только встроенная тема. (3) Настройки: категория «Редактор» убрана, всё — в «Оформление» (DESIGN «Настройки → Оформление»): три плитки тем с кодом в паре, затем «Редактор»: сегмент «Как у темы / Своя», подсказка, «Сбросить всё» (возвращает «Как у темы» и удаляет все ключи темы редактора), «Цвета», опции. «Своя» из сегмента возвращает сохранённые цвета на их основе (или пустую «Свою» на паре); «Как у темы» их не стирает — путь назад. Но изменение цвета в «Как у темы» начинает **новую** «Свою» на паре: скрытые `editor_color_*` удаляются из файла в той же записи, без вопроса (их не видно на экране); превью перетаскивания их тоже не показывает. `ConfirmSheet` «Заменить свою тему?» остаётся только для явных встроенных тем v0.7.0. Значения по умолчанию в файл не пишутся (`editor_palette`, основа Dark Modern — ключи удаляются). (4) «Формат при сохранении» и «Языковые серверы» — в «Дополнительно»: это поведение через tsserver / LSP, не вид. (5) Фон терминала: настройки «Фон терминала: как тема / из Ghostty» больше нет — фон темы всегда кладётся файлом `overrides` после конфига Ghostty пользователя (перекрывает его `background` и тему); туда же — цвет текста (`foreground` = `text` темы) и курсора (`cursor-color` = `accent`), иначе у светлой Ghostty-темы тёмный текст и курсор пропали бы на тёмном фоне; палитра ANSI пользователя по-прежнему побеждает; `TerminalColors.forceBackground`, `userSets().background` и команда отладки `termbg` убраны; ключ `terminal_background` с любым значением молча пропускается (старые конфиги грузятся без предупреждения). Конфиг Ghostty пользователя не трогается. (6) Окно настроек по умолчанию 970 × 600 (минимум прежний, 680 × 440); имя автосохранения рамки сменено на `HangarSettings2`, чтобы сохранённые 760 × 560 не держали окно узким. На странице от 712 pt превью цветов стоит справа от списка (400, закреплено при прокрутке — закреплённый заголовок нулевой высоты), уже — над списком, как в HD-108. **Отвергнуто:** отдельная палитра для Графита (Dark+ уже даёт его серые); «Как у темы» только для чтения (изменение просто делает «Свою»).
