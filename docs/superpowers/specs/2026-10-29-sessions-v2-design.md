# «Сессии» v2 — записка к макету

Макет: `docs/superpowers/mockups/sessions-v2.html` (A — список, рекомендую; B — список + панель). Статус: на согласовании у владельца, кода нет.

## Почему
Слова владельца (2026-10-29): «экран очень неудобный»; «квадратики у закрытых сессий непонятные»; «как я должен понять, что тут сессии только ssh»; «выбранная таба с серваками отображается одинаково с кнопкой новой сессии»; «если сессия была открыта не через ворктри — открыть бы её через него».

Сейчас (`SessionsView.swift`): два несвязанных списка («Закрытые сессии» с глифом раскладки вкладок, «Разговоры» по дням), охват — текст «Проекты на devbox ▾» в строке-счётчике, выбранный сегмент агента залит `moreBg` — тем же серым, что кнопки B′ под курсором.

## Поведение (вариант A)
- **Строка = беседа** Claude/Codex. Группы — по проекту в порядке сайдбара, внутри — по последней активности; заголовков дней нет, время справа («12:40», «вчера», «21 окт.»). Группа длиннее 5 строк свёрнута до 5 + «Показать ещё N». Заголовок группы сворачивается.
- **Строка:** иконка агента · название · где шла беседа (папка — основная папка проекта, ⎇ — ворктри) и ветка моно · состояние · время. Хост — только в заголовке группы и только при охвате «Все» (без повторов, #106). Сессия Hangar, путь, число сообщений — в тултипе строки.
- **Состояние словом** вместо квадратиков: «открыт» (точка статуса агента), «в архиве» (беседа в архивной сессии Hangar), «в истории» (только в файлах агента). Архивные сессии без бесед (только терминалы) — см. вопрос 2.
- **Охват** — сегмент в шапке: «Все» (⌘Y, по умолчанию) / «Этот Mac» / хосты (иконка сервера + точка связи `done`/`idle`; больше трёх — «Ещё ▾»). Выбранный — `accent` 14 % + рамка 25 % + `accentText` (как `ModeChip`), не серая заливка. «Сессии проекта» из меню проекта = охват «Все» + имя проекта в поиске (отдельного режима нет). Это решает «только ssh» и «выбранное как кнопка».
- **Фильтры** — чипы под шапкой, мультивыбор, ничего не выбрано = все: Claude, Codex | Открытые, В архиве, В истории; «Сбросить» (header-action) при любом выбранном. Поиск — по названию, ветке, проекту, хосту, имени сессии.
- **Действия под курсором** (состояние и время прячутся, B′): открыт — «Перейти» (primary); в архиве — «Восстановить» (primary) + корзина; в истории — «Продолжить» (primary, как сейчас: в сессии ворктри этой папки или новая сессия в основной папке) и «Открыть в ворктри» (secondary). ↩ — главное действие, ⌥↩ — «Открыть в ворктри», ↑↓ — по строкам.
- **Состояния:** загрузка — строки этого Mac сразу, у хоста в его группе «Читаю историю на devbox…» со спиннером; повторная загрузка подменяет список целиком в конце (как сейчас, без прыжков). Таймаут/ошибка — строка в группе хоста «devbox не ответил за 20 с» + «Повторить», текст ssh в тултипе. Хост без связи при выбранном хосте — по центру «Нет связи с gpu-box» + «Подключиться»; при «Все» — строка в группе. Пусто — «Здесь появятся беседы Claude и Codex…»; ничего не найдено — «По запросу «…» ничего нет» + «Сбросить фильтры». Таймауты прежние (60 с / 20 с).

## «Открыть в ворктри»
**Когда видна:** беседа шла в **основной папке** проекта (`cwd` = путь проекта, не ворктри сессии и не вложенная папка-проект), ветка известна, не detached. Беседы из ворктри кнопки не имеют — их «Продолжить» уже открывает их ворктри.

**Как узнаём ветку:** Claude — поле `gitBranch` строк jsonl, берём последнее непустое (ветка на момент последней реплики; уже так в `History.swift`). Codex — `session_meta.payload.git.branch`, это ветка **на старте** беседы (переключение в середине не видно). `HEAD` = «detached» или пусто → кнопки нет.

**Когда недоступна (по умолчанию — .38 и причина в тултипе), проверка по `git worktree list --porcelain` при наведении/открытии экрана, с кешем на проект:**
- ветка выгружена в основной папке → «Ветка main занята основной папкой shop. Git не выгружает одну ветку в два ворктри…» (правило владельца);
- ветка выгружена в чужом ворктри (не сессии Hangar) → «Ветка уже в ворктри <путь>» (вопрос 4);
- ветки нет локально → если есть `origin/<ветка>` — доступна (ворктри с отслеживанием), иначе недоступна «Ветки feature-x больше нет»;
- хост без связи → недоступна «Нет связи с devbox».
Если у ветки уже есть **открытая сессия Hangar с ворктри** — это не «Открыть в ворктри», а «Продолжить» в той сессии (новая вкладка).

**Поток:** `git worktree add <путь> <ветка>` (`Git.addWorktree(path:existingBranch:)`, путь — `worktreePath(projectPath:root:branch:)` как у новой сессии; для удалённой ветки — `-b <ветка> --track origin/<ветка>`), затем новая сессия Hangar с этим ворктри (имя — `sessionName(title)`), в первой вкладке — продолжение беседы. Пока идёт — «Создаю ворктри…» на месте действий; ошибка git — «Не удалось создать ворктри» + «Повторить», текст git в тултипе, экран не закрывается; готово — экран закрывается, выбрана новая сессия. Удалённый проект — то же через runner хоста.

**Продолжение в другой папке (риск, проверить перед кодом):**
- Claude хранит беседу в `~/.claude/projects/<cwd с заменой не-букв на ->/<id>.jsonl`, и `claude --resume <id>` ищет её по **текущей** папке. Из ворктри беседа основной папки не найдётся. Решение: скопировать jsonl в папку проекта ворктри (оригинал не трогать) и продолжить там. Это запись в `~/.claude` — нужно согласие владельца (AGENTS.md), вопрос 3. Проверить на текущей версии claude: возможно, `--resume <id>` уже ищет по всем проектам.
- Codex: `codex resume <id>` находит rollout по id глобально, рабочая папка — текущая (`-C`). Проверить, что он не возвращается в старый `cwd`.

**Незакоммиченные изменения:** правки беседы, не закоммиченные в основной папке, в ворктри не попадут. Если `git status --porcelain` основной папки не пуст — в тултипе кнопки вторая строка «Незакоммиченные изменения основной папки останутся там»; кнопка остаётся доступной (это не потеря данных: файлы не трогаем).

**Предложение (вопрос 1):** в «⋯» строки — «В новой ветке от main…»: лист «Новая сессия» с ворктри, «От ветки» = ветка беседы, имя новой ветки — из названия; после «Создать» беседа продолжается в ней. Работает и когда ветка занята. По умолчанию не делаем.

## Вариант B
Те же строки, справа панель 372 выбранной беседы: где, ветка, сессия, сообщений/начата, последнее сообщение (новое: чтение хвоста файла), действия с причиной недоступности словами. Минус — две колонки на 13", повтор ветки в строке и панели, лишнее чтение файлов. Превью при желании можно дать в A тултипом.

## Края
- Одна беседа в нескольких местах: открыта — «открыт» побеждает «в архиве».
- Беседа из папки, которой больше нет (ворктри удалён руками): «Продолжить» → новая сессия в основной папке (как сейчас), «Открыть в ворктри» — по ветке, если есть.
- Беседа без названия — «Без названия»; без сообщений не показывается (как сейчас).
- Ветка `main` в основной папке — самый частый случай: кнопка будет недоступна у большинства старых бесед основной папки; поэтому причина короткая и одна.
- Охват хоста, у которого удалены все проекты, — сегмент исчезает, охват → «Все».
