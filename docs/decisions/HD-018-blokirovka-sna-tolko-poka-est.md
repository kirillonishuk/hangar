# HD-018 — 2026-10-18 — Блокировка сна только пока есть вкладки в `working` (+2 мин), `IOPMAssertion` без root; вкл/выкл в настройках и ☕ в сайдбаре.

Почему: Mac не должен спать во время работы агентов, но и не держать бодрствование «просто открытым окном». Отвергнуто: закрытая крышка через `pmset disablesleep` (root, перегрев).
