# HD-154 — 2026-11-13 — Архив спрашивает до остановки вкладок; кэши инструментов не «файлы вне git»; чат после архива (слово владельца; дополняет HD-057, HD-132).

Владелец: «удаляю ворктри — оно пропадает, потом появляется и выскакивает модалка "В копии есть файлы вне git: .claude/.cache/"; хотелось бы историю чатов хранить». (1) **Сначала вопрос.** Было (HD-057): вкладки останавливались и сессия уходила в архив до проверки, а при риске возвращалась обратно — сессия исчезала из сайдбара и появлялась уже с вопросом. Теперь `archiveOne` без `force` сначала проверяет папку (`checkWorktree`, та же функция; оверрайд строки состояния HD-105 на время проверки снимается и возвращается) — при риске `.atRisk`, ничего не остановлено и не заархивировано. Чистая папка — дальше как раньше: остановка, повторная проверка (агент мог дописать в промежутке; тогда, как раньше, сессия возвращается) и удаление. «В архив всё равно» (`force`) — без предварительной проверки. CLI `sessions archive` и MCP получают `confirm_required` так же, без перезапуска вкладок. (2) **Кэши — не потеря.** К переустанавливаемым (`isReinstallable`: `node_modules`, `.venv`, `.turbo`, `dist`, `vendor/bundle`) добавлены кэши инструментов и мусор Finder по последней компоненте пути: `.cache` (в т.ч. `.claude/.cache` Claude Code), `__pycache__`, `.pytest_cache`, `.mypy_cache`, `.ruff_cache`, `.next`, `.build`, `.DS_Store`. `.claude/settings.local.json`, `.claude/worktrees/` и весь `.claude/` одной записью (git сворачивает папку, где игнорируется всё) по-прежнему спрашивают. (3) **Чат не в копии.** Разговор агента лежит у агента (`~/.claude/projects/<папка>/<id>.jsonl`, у Codex — `~/.codex/sessions`), архив его не трогает; запись сессии остаётся в архиве («Сессии», ⌘Y), ветка остаётся (HD-057). «Восстановить» заново создаёт копию из ветки по тому же пути, и вкладка claude продолжает тот же разговор (`--resume <id>`, HD-119) — проверено. Удаляет запись только «Удалить навсегда». Ограничение вне Hangar: Claude Code сам чистит старые транскрипты (`cleanupPeriodDays`, по умолчанию 30 дней). **Отвергнуто:** не прятать сессию до ответа без предварительной проверки (лишняя остановка агента ради вопроса, на который можно ответить, не трогая его); `status --ignored=matching` (разворачивает папки в списки файлов — тысячи аргументов у `ignoredAtRisk`); копировать транскрипт в архив Hangar (он и так вне копии).
