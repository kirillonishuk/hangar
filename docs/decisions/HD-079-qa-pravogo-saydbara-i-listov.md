# HD-079 — 2026-10-26 — QA правого сайдбара и листов: необязательные инструменты сервера — по галочке.

В плане установки «Сервер» codex и hx (`RemoteTool.optionalInstalls`) не ставятся по умолчанию: под планом «Необязательно: ☐ codex ☐ hx» (только отсутствующие, сняты); отмеченный входит в показанные команды, и «Установить» запускает ровно их (`installPlan(…, optional:)`); неотмеченный не попадает и в «установите сами». Статус интеграций в настройках и в «Сервер» — одна строка с обрезкой посередине и полным текстом в подсказке; красный — только для ошибки, «не установлена» / «устарела» — `waiting` (янтарный). Files пустой папки — «Папка пуста», папки репозитория без файлов — «Нет файлов в git» (после загрузки, `InspectorModel.treeLoaded`). Почему: QA области 3 (лишняя установка без спроса, красный для не-ошибки, пустой экран без объяснения).
