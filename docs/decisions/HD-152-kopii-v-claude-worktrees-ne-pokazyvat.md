# HD-152 — 2026-11-06 — «Копии без чата» не показывает ни одну копию из `.claude/worktrees/` проекта; баннер — не для `agent-<hex>` (слово владельца; заменяет правило HD-147, уточняет HD-134 (1), (4)).

Папка `<проект>/.claude/worktrees/` — территория Claude Code: копии субагентов `agent-<hex>` и копии, которые оркестрирующий агент делает под параллельные потоки (`aut-1076-admin`). Правило HD-147 (путь И ветка `worktree-agent-<hex>` / блокировка `claude agent …`) пропускало копии с переименованной веткой без блокировки (`agent-a820a2326a0bbfb3c`, ветка `aut-1076-lead07-web`). Теперь: (1) «Копии без чата · N» не содержит ни одной копии, лежащей в `.claude/worktrees/` проекта; копии в других местах (`<проект>.worktrees/…`, соседние папки) показываются как раньше, копия с чатом (открытым или в архиве) и так не «без чата». (2) Баннер «Агент работает в копии …» (HD-134) не показывается для cwd в копии `agent-<hex>`: последняя компонента пути `agent-[0-9a-f]{16,}` прямо под `.claude/worktrees/`, ветка и блокировка не смотрятся; для остальных копий в этой папке (`EnterWorktree`, `aut-1076`) баннер остаётся. Пути сверяются по realpath от корня главного checkout (без ложного срабатывания, когда `.claude/worktrees` лежит выше проекта). Строка в настройках проекта «Копии внутри проекта не скрыты от git» (HD-134 (3)) остаётся: такие копии по-прежнему засоряют `git add -A`. **Отвергнуто:** оставить признак по ветке/блокировке (HD-147) — теряет копии с переименованной веткой.
