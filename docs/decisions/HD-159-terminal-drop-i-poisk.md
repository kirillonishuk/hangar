# HD-159 — 2026-11-13 — Перетаскивание в терминал и поиск ⌘F в терминале

**Перетаскивание.** Терминал принимает перетаскивание (файлы, URL, текст). Файлы — из Finder, миниатюры снимка экрана, строк «Файлы» и «Изменения» инспектора — вставляются как ⌘V: пути экранированы для shell и разделены пробелом, другой URL — как есть, текст — как есть. Одна функция (`TerminalSurfaceView.pasteText`) для ⌘V и перетаскивания; вставка — обычной вставкой Ghostty (bracketed paste, без ↩), терминал получает клавиатуру. Строки «Файлы» и «Изменения» отдают файл как file URL (в терминал, Finder, другое приложение); клик, двойной клик и меню строк не меняются. Источник — сессия перетаскивания AppKit из жеста строки (`HoverRow.dragFile`): SwiftUI `onDrag` не стартует поверх жеста нажатия строки. Не перетаскиваются: файлы проекта на сервере (путь сервера бессмыслен для Finder и локального shell) и удалённые файлы «Изменений». Файл из «Файлов» чата без проекта, брошенный в тот же список, не копируется второй раз.

**Поиск в терминале.** ⌘F (keyCode 3) с клавиатурой в терминале или в его строке поиска открывает поиск Ghostty по прокрутке (`start_search`), раньше поиска вкладки Git: Git-поиск получает ⌘F, только когда клавиатура не в терминале. Строка поиска — полоса под заголовком панели в его виде (`barPane` 28, `bg0`, линия снизу, шрифт `secondary`): лупа, поле «Найти в терминале», счётчик «N из M» («– из M», пока совпадение не выбрано; «Нет совпадений»), ↑ ↓, ×. ↩ — совпадение выше, ⇧↩ — ниже (порядок Ghostty — снизу вверх, как его ↩), Esc и × закрывают и возвращают клавиатуру терминалу; Esc в терминале при открытом поиске тоже закрывает (привязка Ghostty `end_search`). ⌘E (поиск выделенного), ⌘G / ⇧⌘G — привязки Ghostty, работают с той же строкой. Строка сдвигает терминал вниз на свою высоту (как нижняя полоса «↩ — перезапустить»), а не перекрывает первую строку экрана. Поле из 1–2 символов ищет через 0,3 с (как в Ghostty: короткая строка совпадает с половиной прокрутки). Ghostty сообщает итог действиями `START_SEARCH` / `END_SEARCH` / `SEARCH_TOTAL` / `SEARCH_SELECTED`; вызовы — `ghostty_surface_binding_action` (`search:<текст>`, `navigate_search:next|previous`, `end_search`), только в `GhosttyBridge`.

**Почему.** Ревью: пути попадали в терминал только через буфер, а ⌘F в терминале ничего не делал (действия поиска GhosttyKit не обрабатывались). Всё — AppKit и API GhosttyKit, без зависимостей.

**Ограничения (shortcut).** Файл-обещание без file URL (картинка из браузера и т. п.) терминал не принимает. Перетаскивание строк инспектора у проекта на сервере не включено — добавить вставку пути сервера текстом, если попросят.
