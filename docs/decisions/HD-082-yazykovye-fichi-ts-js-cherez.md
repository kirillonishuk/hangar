# HD-082 — 2026-10-26 — Языковые фичи TS/JS через tsserver проекта (трек M2, дополняет HD-080).

По слову пользователя: переход к определению функций и классов через вложенные ссылки, ссылки, hover, ошибки; легко. Ничего не ставится: Hangar ищет `node_modules/typescript/lib/tsserver.js` вверх от папки файла до корня сессии (pnpm-монорепо — в корне, у пакета может быть свой) и запускает его `node` пользователя (логин-шелл, иначе `/usr/local/bin/node`, `/opt/homebrew/bin/node`; на хосте — `command -v node` с логин-PATH проверки сервера) с `--max-old-space-size=2048 --disableAutomaticTypingAcquisition --noGetErrOnBackgroundUpdate --locale ru|en`. Один процесс на (хост, tsserver.js), запуск при первом открытом TS/JS-файле, остановка через 120 с после закрытия последнего (одна одноразовая задача, без опроса), после падения — один перезапуск с повторным `open` текстов из страницы, второе падение — статус «TS остановлен», клик — заново. На сервере — тот же процесс через `ssh -T` по мастеру (`sshStreamArgs`), конец — EOF stdin; нет node/typescript или хост не подключён — спокойный статус, фичи просто не работают. Протокол: запросы — JSON-строки, ответы — `Content-Length`-кадры (`TsFramer`: сообщение > 32 МБ пропускается, мусорные заголовки отбрасываются, не-объекты и неизвестные события игнорируются). Синхронизация: `open` (текст при загрузке; правки до старта буферизуются), инкрементальные `change` из `onDidChangeContent` Monaco, `close`; `geterr` через 400 мс после правок → маркеры (syntax + semantic). Запросы: `definitionAndBoundSpan`, `references` (+ тексты чужих файлов для превью peek, ≤ 30), `quickinfo` → markdown, `completionInfo` + `completionEntryDetails` по выбору, `rename` (пункт меню и F2, только TS/JS; правки — Monaco в открытой модели, она же шлёт их в tsserver) и `configure` + `format` всего файла с отступом редактора (⇧⌥F). `shortcut:` переименование, которое задевает другие файлы, отклоняется сообщением (не пишем частично в неоткрытые файлы) — снять, когда редактор научится применять правки к закрытым файлам. Пути из ответов — только внутри корня сессии (и его realpath) или в `node_modules`, без `..`; прочее отбрасывается; файлы из `node_modules` открываются только для чтения. Все переходы идут через editor opener страницы: тот же файл — на месте, другой — открывается в этой вкладке; история ⌃- / ⌃⇧- (50 позиций, только в странице). Языковые сервисы Monaco (TS-воркер) остаются выключены, подсветка — Monarch. Статус — в полосе вкладок файлов (DESIGN.md). `editorProvider` заменён на `AppState.languages`. `shortcut:` diff-вкладка не синхронизирует буфер с tsserver (ответы — только для файла, открытого и в редакторе); Swift (sourcekit-lsp из Xcode), Python и Go — позже, отдельным LSP-клиентом рядом с `Languages`.
