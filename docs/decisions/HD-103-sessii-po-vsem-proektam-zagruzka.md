# HD-103 — 2026-10-29 — «Сессии» по всем проектам, загрузка всегда заканчивается, продолжение именно выбранного разговора; «ошибки» в строке состояния — только агенты (отзыв владельца по v0.4.4, дополняет #76, #97).

(1) ⌘Y показывает закрытые сессии и разговоры **всех** проектов: при выбранном терминале хоста (#64) вид получал id псевдопроекта, не находил проекта и навсегда оставался в «Загрузка разговоров…» с нулём закрытых. Каждая строка подписана проектом (` · хост` у удалённых, `text3`); сужение — чип в заголовке «Все проекты ▾» (проекты, «Проекты на <хост>», «×» — обратно ко всем); из меню проекта («Сессии проекта»), подсказки под проектом и ссылки `hangar://sessions/<проект>` вид открывается уже суженным. (2) Загрузка всегда заканчивается: сначала этот Mac, затем каждый хост; таймаут на вызов — 20 с удалённо (ssh убивается), 60 с локально (локальный скан проверяет отмену между файлами и отдаёт уже разобранное — эти строки остаются); новый скан (смена охвата, «Повторить») отменяет идущий, кэш пишет только текущую версию файла; ошибка или молчание источника — строка «Не удалось загрузить с <хост>: …» с «Повторить», строки остальных источников остаются; хост без связи — «Нет связи с <хост>». При первой загрузке строки появляются по мере чтения папок, при пересканировании подменяются в конце (список не прыгает). Разбор локальных файлов — параллельно по ядрам: 1100 файлов / 1,5 ГБ (20 проектов) — холодный проход ≈ 3,9 с при чтении 216 МБ (головы и хвосты), повторный ≈ 0,07 с (замер `HANGAR_SCAN_BENCH=1 swift test --filter scanBenchmark`). (3) Клик по разговору продолжает **именно его** (`claude --resume <id>` в записанном `cwd`): «открыт»/«Перейти» — только если живой лист того же агента на той же машине держит этот id (вкладка или панель TERMINAL, в любом проекте — тогда переход туда, без второго `--resume`); закрытая сессия восстанавливается, только если её агент держит этот id (раньше клик по разговору из папки с закрытой сессией восстанавливал ту сессию с её собственными агентами — «пустая сессия», а следующий разговор той же папки открывался в ней же). Разговор главной папки, который нигде не открыт, получает собственную сессию с его именем; разговор папки worktree — новую вкладку в открытой сессии этого worktree. Id из файла проверяется до создания сессии (неверный — ничего не открывается), имя сессии — одна безопасная строка до 40 символов. Действие при наведении: «Перейти» / «Продолжить» (для закрытой сессии Hangar — «Восстановить»). (4) «● N ошибка» в строке состояния считает только агентов (claude/codex): ненулевой выход оболочки или терминала хоста (ssh 255 при обрыве) оставляет точку вкладки и строку «процесс завершился с кодом N · ↩ перезапустить», но не ошибку; клик по счётчику показывает сессию и вкладку первого упавшего агента и открывает «Входящие». (5) Проект, у которого все сессии в архиве, под заголовком показывает «Все сессии в архиве», «Открыть сессии ⌘Y» (суженные до проекта) и «+ Новая сессия». (6) «+ Новая сессия» в сайдбаре — кнопка с рамкой `controlBorderStrong` и текстом `accentText` (заливка только при наведении), чтобы не совпадать с выбранной строкой «Сессии» (`selection`).
