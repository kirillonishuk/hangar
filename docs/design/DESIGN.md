# Hangar — дизайн-система

Стиль A «Ghostty-native»: тёмный, плотный, без декора. Значения взяты из CSS эталонных макетов (`docs/superpowers/mockups/style-a-v2.html`, `new-task-v4.html`, `limits.html`). Размеры в макетах — px, в приложении — pt 1:1. Только тёмная тема в v1.

Терминал (шрифт, размер, цвета текста) берётся из конфига Ghostty пользователя; фон и ANSI-палитра по умолчанию — из темы Hangar, если пользователь не задал свои (см. «Цвета», решения #36, #85).

## Решения пользователя, из которых выросла раскладка
- Одна строка заголовка на всю ширину окна; под ней сайдбар, область сессии и правый сайдбар; внизу — строка состояния окна (redesign-v1).
- Вкладки — внутри области сессии, не сверху окна (`style-a-screens.html` с верхними вкладками устарел).
- Слева в полосе вкладок — название сессии и `⎇`.
- Лист новой сессии широкий (≥ 580), подписи в одну строку, настройки — одной карточкой.
- Агент по умолчанию claude; выбора агента в листе нет, другие — через `+` во вкладках.

## Цвета

Три темы (макет `docs/superpowers/mockups/themes-v1.html`, решение #85): **A «VS Code Dark+»** — по умолчанию, **B «Графит»**, **C «Hangar Navy»**. Выбор — Настройки → Оформление → Тема, в конфиге `theme = "dark-plus" | "graphite" | "navy"`; переключение живое (без перезапуска и без сдвигов раскладки). Источник правды в коде — `ThemePalette` (`Sources/HangarUI/ThemePalette.swift`), имена токенов как в макете; тест сверяет каждую тему с макетом и проверяет контраст. Размеры, отступы, радиусы от темы не зависят. Только тёмные темы; системный режим не отслеживается.

Производные (в макете нет строки): `pressed` — середина `bg`→`hover`; `sidebarPressed` — `sidebar` на 15% темнее; плитка рейки `railTile` = `sbHover`, рамка `controlStrong`; выбранная — `selected` с 20% / 40% `accent`. Наведение на кнопку строки — белый 7%; деструктивный пункт меню — `failedText`, фон `failed` 14%.

ANSI-палитра терминала (0–7, 8–15):
- Dark+: `#000000 #cd3131 #0dbc79 #e5e510 #2472c8 #bc3fbc #11a8cd #e5e5e5`, `#666666 #f14c4c #23d18b #f5f543 #3b8eea #d670d6 #29b8db #ffffff`

Терминал: фон `termBg` и палитра темы передаются Ghostty файлом `hangar-ghostty-defaults-<pid>.conf`, который грузится до конфига пользователя, — поэтому `background` / `palette` / `theme` пользователя побеждают (если в его конфиге или теме они есть, Hangar их не подставляет). «Фон терминала: как тема» (`terminal_background = "hangar"`, по умолчанию) кладёт фон темы ещё и после конфига пользователя — он перекрывает и его тему (решение #36); «из Ghostty» (`"ghostty"`; прежнее `"theme"` читается так же) оставляет фон Ghostty. Смена темы и этой настройки применяется к терминалам, открытым после неё (`ghostty_app_update_config`); открытые сохраняют прежний фон до перезапуска вкладки — `ghostty_surface_update_config` заново накладывает тему Ghostty пользователя поверх фона Hangar (проверено вживую). Файл конфига Ghostty Hangar не меняет.

Контраст (WCAG AA, проверяется тестом): `text`/`text2` ≥ 4.5 на `bg`, `sidebar`, `panel`, `sheet`, `selected`, `sbHover`, `tabInactive`; `primaryText` на `primary`, `menuHoverText` на `menuHover`, `failedText` на `sidebar` ≥ 4.5; `text3` на `sidebar` ≥ 3.

Редактор: синтаксис — VS Code Dark+ во всех темах (или приглушённая палитра Hangar, Настройки → Редактор, #84); от темы — фон, номера строк, текущая строка, выделение, направляющие, фон diff. Подсветка синтаксиса в SwiftUI-diff листа интеграции (решение #53): keyword `#b79bd9`, string `#a9c48f`, comment `#75819a`, number `#d5a274`, type `#dcc283`; остальное — `text`; заголовок ханка — `accentText` на нём же 7%.

Лимиты: дорожка `limTrack`; `limOk` (< 80%), `waiting` (≥ 80%, «почти лимит»), `failed` (≥ 95% или исчерпан; текст процента `failedText`). Бейджи — фон того же цвета 15%. Статусы — точка 8 pt; `limit` агента — цветом `waiting`. Git: `?` цветом A, `R` цветом M, `U` цветом D.

## Типографика
- Шкала на ступень крупнее макетов (решение #34). UI — системный шрифт (SF Pro). Базовый 13; строки сессий и файлов 13; строки в листе и любой ввод текста 13.5 (`Theme.Input`); заголовок листа 14.5; заголовок в строке заголовка («Проект · Сессия») 13; заголовок поповера 13 bold.
- Вкладки 12.5; подписи сегмента 12; строка состояния, счётчики 11.5.
- Нижняя граница — 11.5 (`fontSize.small`): мельче ничего нет, кроме бейджей лимитов (11). Подсказки клавиш (⌘0, ⇧⌘N) — 12 `text3`, одним видом `ShortcutHint`, текст — `Shortcut.label`.
- Сайдбар (как в Pane): заголовки секций 11.5 semibold с разрядкой, строки (сессии, проекты, «+ Новая сессия») 13.5, нижние кнопки (Настройки) 13, высота строки 32.
- Моно (`JetBrains Mono` → `SF Mono` → Menlo): пути, ветки, имена файлов в diff, номера строк, команды. В терминале — шрифт Ghostty.
- Капс + разрядка `.06em` — только заголовки секций сайдбара (`ЗАКРЕПЛЁННЫЕ`, `ПРОЕКТЫ`, `АРХИВ`) и секции выпадающего списка веток. Больше нигде.
- Иконки — SF Symbols через один `enum Icon`, вес regular, 15 pt, цвет `text2` (выбранное — `textStrong`); агенты — логотипы (Claude `#d97757`, OpenAI белым).
- Иконка приложения — концепт A (ворота ангара с `>_`) в цветах Dark+, тело — squircle (решение #92, `app-icon-v2.html`, вариант A1); исходники: `docs/superpowers/mockups/app-icon/A-master.svg` и `A-small.svg`, сборка `scripts/make-icon.sh` → `Resources/AppIcon.icns`.
- Установщик DMG — `scripts/bundle.sh && scripts/make-dmg.sh` → `build/Hangar.dmg`: окно 640×400 на navy-фоне (`scripts/dmg-background.swift`), Hangar слева, «Программы» справа, стрелка и подпись ru/en; при первом запуске разрешить Terminal управлять Finder.

- Окно: радиус 12, без отдельного тулбара. Строка заголовка 38 на всю ширину (`titlebar`, нижняя граница `line`): светофор (системный), переключатель сайдбара на x 84 (`titlebarToggleX`, не двигается при сворачивании; тултип «Свернуть сайдбар — ⌘0» / «Развернуть сайдбар — ⌘0»), по центру «Проект · Сессия ⎇ ветка» (проект `text2`, сессия `textStrong` 500, 13; ветка — иконка 12 + моно 12 `text3`, только у worktree-сессии; терминал хоста — «хост · терминал»), справа переключатель правого сайдбара (⌥⌘I). Кнопки 28×28, радиус 6, иконка 16, подложка `hover`. Двойной клик по пустому месту заголовка — как в системе (`AppleActionOnDoubleClick`: развернуть/свернуть).
- Область сессии: полоса вкладок 34 (`tabStrip`, нижняя граница `line`; вкладки — `tabInactive`, активная — `tabActive` с полосой `accent` 2 pt сверху) сразу под строкой заголовка.
- Сайдбар: ширина 240 по умолчанию, перетаскиванием 200–320 (решение #23), сохраняется в состоянии; сворачивается в рейку 44 (`⌘0`, решение #32). У каждой строки слева жёлобок 44: точка/иконка стоит на одном x в обоих режимах, при сворачивании анимируется только ширина (180 мс), текст гаснет и обрезается.
- Сайдбар сверху вниз: «Новая сессия» и «Сессии» (обычные строки 32, как остальные: наведение `sidebarHover`, без рамки и заливки в покое, без клавиш в строке; только «+» «Новой сессии» — `accentText`; клавиши в тултипах «Новая сессия — ⌘N» / «Сессии — ⌘Y»; в рейке — одна иконка; выбранная «Сессии» — `selection`, #103; `sidebar-new-session.html`, вариант B); `ЗАКРЕПЛЁННЫЕ` (скрыта, если пусто; строка — имя сессии и проект `text3`, булавка при наведении/закреплении); `SSH-ХОСТЫ` (скрыта без удалённых проектов; строка хоста — иконка `sshHost` 13 в жёлобке, имя системным 13, справа состояние 11.5 `text3`: подключён / подключение… / переподключение… / нет связи (повтор ждёт активации) / недоступен / не подключён; точка `waiting` 7 в углу иконки, если на сервере чего-то не хватает; «…» при наведении; клик — меню у курсора «Переподключиться» / «Проверить сервер» / «Отключиться»; в рейке видна только иконка); `ПРОЕКТЫ` (`+` при наведении — меню «Локальная папка…» / «Удалённый (SSH)…», то же у ⌘⇧N и «+ Добавить проект»; у удалённого проекта после имени — иконка `sshHost` 13 и хост 11.5 `text3` (в рейке — обычная монограмма); сессии недоступного хоста — прозрачность .38, в их меню первым «Переподключиться»): сворачиваемые группы (шеврон, имя проекта semibold, `+` при наведении — новая сессия), сессии с отступом (иконка worktree или точка статуса); внизу сворачиваемый `АРХИВ N`. ## Без повторов (#106)
Одна и та же информация на экране — в одном месте. Перед тем как добавить подпись, счётчик или путь, проверь, не видно ли это уже рядом; если видно — не добавляй, а где повтор есть — убери лишний. Примеры: проект — только в заголовке окна (и выбранной строкой сайдбара), не в строке состояния; число изменений — бейдж Changes, не «3 файла» в заголовке списка; `+N −M` — строка Changes, не заголовок diff; имя вкладки сплита — первая панель, не склейка заголовков панелей; путь — в поле, не ещё раз подсказкой под ним; ошибка агента — точка вкладки, строка сайдбара, «N ошибка» в строке состояния и колокольчик, но не «ждёт внимания». Подробности, которые нужны редко, — в тултип.

## Сайдбар: свёрнутый режим
- Жёлобок фиксированный, 44 pt; строки 32 (`railRowHeight`). Маркер (точка/иконка) стоит на одном x в обоих режимах.
- Монограмма сессии: имя делится по `-`, `_`, `.`, пробелу и границе camelCase; 2+ части — две первые буквы, одна часть — одна буква.

## Правила
- Нет капса, кроме заголовков проектов в сайдбаре (и секций пикера веток).
- В листах нет переносов подписей: `white-space: nowrap`, лист ≥ 580.
- Настройки в листе — одна карточка строк, а не набор полей с подписями сверху.
- Цвет статуса — только точкой (и ореолом для waiting), не заливкой строки.
- Никаких сторонних UI-китов: системные контролы, перекрашенные под токены.
- **Курсор: рука на всём кликабельном.** `NSCursor.pointingHand` при наведении на кнопки (+ «Новая сессия», `+` у заголовков, шестерёнка, «…», переключатели сайдбаров в заголовке, счётчики строки состояния, кнопки листов и окна настроек, сегменты), строки сайдбара (сессии, проекты, архив, плитки рейки, шевроны), вкладки и их `×`, `+` полосы вкладок, полосу «↩ перезапустить» у вышедшего/упавшего листа. Один модификатор `.pointingHand()` (macOS 15+: `pointerStyle(.link)`, иначе сбалансированные `push`/`pop` с `pop` при исчезновении); в AppKit — `addCursorRect`. Поля ввода — I-beam (и инлайн-переименование внутри строки), терминал — курсор Ghostty, разделители сплитов и сайдбара — курсор изменения размера.
- Никаких строк литералами в UI: каждая видимая строка — через `L10n` (`ru` и `en` в `Resources/*.lproj/Localizable.strings`). Литералом можно только имена продуктов и команд (Claude, Codex, Shell, Hangar, Monaco) и символы клавиш (⌘N).
- **Окно настроек** (`⌘,`, как Системные настройки / настройки VS Code; 760×560, изменяемое, мин. 680×440, размер запоминается; фон `sheet`). ## Перенос в SwiftUI
Один `enum Theme` (без экземпляров) с вложенными пространствами: `Theme.Color` (токены выше как `Color`/`NSColor`), `Theme.Status` (функция `color(for: AgentState)`), `Theme.Limit` (`color(forPercent:)` с порогами 80/95), `Theme.Font` (`ui`, `uiSmall`, `mono`…), `Theme.Metric` (ширины сайдбара/инспектора, высоты полосы вкладок/строки состояния, радиусы). Пороги 80/95 — константы в одном месте, их же использует логика уведомлений. Литералы цветов и размеров во view запрещены.
