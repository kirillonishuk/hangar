# HD-130 — 2026-11-04 — «Все чаты (N)…» только когда ведёт к скрытым чатам; точка «простоя» на выбранной строке без обводки (замечания владельца по скриншоту; спеки `specs/2026-10-31-free-chats-design.md` §4.1, `specs/2026-10-30-design-system.md` §2.8 и §3.3; уточняет HD-126).

(1) Строка «Все чаты (N)…» показывалась при любом непустом списке — и при одном чате, который уже виден над ней. Теперь она есть, только если хоть один чат без проекта не показан в секции (`AppState.freeChatsBeyond`: сверка id видимых строк, включая подчаты, с `freeChatTasks`) — за пределом 7 или подчат под свёрнутым родителем. (2) На выбранной строке (`selectedFocus`) точка получала белую обводку 1.5 (§2.8); у «простоя» серая точка в белом кольце выглядела как пустая радиокнопка, а на акцентной заливке серый почти не виден. Теперь «простой» на выбранной строке — точка `onAccent` с прозрачностью .4 (`Opacity.inactive`), без кольца; остальные состояния — как были (цвет статуса + белое кольцо, у «ждёт» ещё ореол). Один параметр `StatusDot(onAccent:)` вместо четырёх копий кольца в сайдбаре (чат без проекта, закреплённый, чат проекта, терминал сервера). Отвергнуто: убрать точку у простоя (имя сдвигать нельзя, а пустой слот читается как спящий чат), серая точка без кольца (на акцентной заливке не видна).
