# HD-146 — 2026-11-06 — Diff: одна колонка для файла с одной стороной, «Переносить строки», свёрнутые неизменённые участки (слово владельца; DESIGN.md «Diff»; дополняет HD-080, HD-135).

Владелец: у нового файла в «Рядом» левая половина пустая и заштрихована (только «1 —»); длинные строки уходят за край; в длинном файле правки теряются среди неизменённого.

1. Файл с одной стороной — `added`, `untracked`, `deleted` (`diffOneSided`): одна колонка во всю ширину независимо от «Рядом / Одной колонкой»; сохранённый выбор не меняется и вернётся на следующем файле. В переключателе выбрано «Одной колонкой», «Рядом» неактивно с тултипом «Файл есть только с одной стороны — одна колонка». Страница прячет пустую сторону: у нового файла — полосу номеров базы и пустую строку, которую Monaco помечает удалённой (пустая модель для него — замена всей строки); у удалённого — пустую рабочую строку. Признак берётся из Changes (`ChangedFile.change`), у файла коммита — из деталей коммита (`DiffTab.change`).
2. Подпись в заголовке diff после пути — `caption` `text3` «новый файл» / «удалён». Правило «одна информация — в одном месте» (HD-106): буква A/D в строке Changes — в другой панели (может быть скрыта) и не объясняет, почему колонка одна, поэтому подпись есть; «Переименован из …» уже показан строкой под заголовком — отдельной подписи у переименования нет.
3. «Переносить строки» — иконка (новый глиф `wrap`) с тултипом перед переключателем колонок, вкл. — `hover2`; `WorkspaceState.diffWrap` (по умолчанию выкл., сохраняется как `diffInline`). Monaco `wordWrap` + `diffWordWrap` (вторая нужна базе в «Рядом»); перекрывает перенос из Настройки → Редактор только в diff.
4. Неизменённое свёрнуто: Monaco 0.57 `hideUnchangedRegions` (контекст 3, сворачивается от 6 строк, раскрытие по 20). Подпись полосы в ru — «Строк без изменений: N» (подмена сообщения Monaco по номеру, с проверкой исходного текста; en — Monaco «N hidden lines»). Изменения не сворачиваются, поэтому F7 / ⇧F7, счётчик «1 из N», прокрутка к первому изменению и ⌘↩ не менялись; курсор, поставленный в свёрнутое, раскрывает участок (Monaco).

Не делали: свой рендер «только добавленные строки» вместо diff-редактора — Monaco с прятанием пустой стороны даёт ту же картинку меньшим кодом.
