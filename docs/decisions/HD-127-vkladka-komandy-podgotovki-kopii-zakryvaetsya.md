# HD-127 — 2026-11-04 — Вкладка команды подготовки копии закрывается сама после успеха (слово владельца: при создании чата в копии открывались две вкладки, вторая лишняя; меняет #58 «после команды остаётся интерактивный shell»).

Вкладка shell с командой подготовки (и строками `hangar: не скопировано …`) по-прежнему создаётся и запускается сразу за вкладкой агента (агент остаётся активным, выбор чата не меняется) — пока команда идёт, её видно. Но команда теперь — весь запуск вкладки: `agentCommand` для shell с `initialPrompt` даёт `<shell> -i -c '<скрипт>'` без интерактивного shell после (отдельный процесс — `exit N` в команде пользователя не обходит обёртку OSC 133 с кодом; `-i` сохраняет функции и алиасы, как раньше; локально и на сервере — один путь, на сервере код идёт через файл выхода tmux). Код 0 → обычное закрытие вкладки по выходу 0 (`leafExited` → `closeLeaf`): без плашки «Процесс завершён…», активная вкладка и фокус не трогаются, если закрытая не была активной. Ненулевой код → вкладка остаётся с выводом, плашка «Процесс завершён с кодом N · Enter — перезапустить» и статус «ошибка» у вкладки и строки чата (существующий путь `.exited(code)`; без «Входящих» — как у любого shell). Ошибка копирования делает код ненулевым (`exit 1` после команды — читается в sh, zsh и fish), чтобы её строки не пропали. Прерывание (Ctrl-C): оболочка обрывается без кода (-1) — у вкладки подготовки это тоже «ошибка» (`AppState.exited`, у прочих shell -1 по-прежнему не ошибка). Вкладки подготовки (`AppState.setupLeaves`, только в памяти) не сохраняются в `state.json` (`savedState` убирает их лист; вкладка уходит, если в ней больше ничего нет) — после перезапуска мёртвой вкладки подготовки нет, команда и так не повторяется. Enter на упавшей вкладке даёт обычный shell в копии, и с этого момента она — обычная вкладка (сохраняется). Почему: владелец не хочет лишнюю вкладку после каждого нового чата; результат команды не терять при ошибке. Отвергнуто: разбор вывода терминала (ненадёжно), отдельный UI-индикатор (есть статус вкладки и плашка), запуск команды без вкладки (ошибку и прогресс негде показать).
