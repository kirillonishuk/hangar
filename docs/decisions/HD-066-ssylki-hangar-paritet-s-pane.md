# HD-066 — 2026-10-24 — Ссылки `hangar://` (паритет с Pane `links_create`).

Схема в `Info.plist` (`CFBundleURLTypes`), обработка — `application(_:open:)`; ссылки, пришедшие до окна (холодный запуск), ждут его. Форма строгая (`HangarLink`, граница доверия — URL открывает любая страница): `hangar://task|tab|project/<hex-id или префикс ≥ 4>`, без query/fragment/user/port; остальное — игнор. Ссылка разрешается как ref CLI (HD-045; архивные не находятся; вкладка — по id вкладки или её панели), только выбирает: задача — выбор, вкладка — выбор задачи, вкладки и фокус её терминала, проект — раскрыть и показать первую задачу, если выбрана задача другого проекта (своего выбора у проекта нет). Ничего не запускается и не создаётся. Неизвестное — `uiLog.error`, без алерта. Ссылки создают `hangar link task|tab|project <ref>` / MCP `links_create` (полный id в нижнем регистре) и пункт «Скопировать ссылку» в меню задачи и вкладки. Отвергнуто: `tasks focus` с запуском и ссылки на файлы/строки — не просили.
