# HD-165 — 2026-11-13 — Многострочный ответ из «Входящих» доходит многострочным; у «Оформления» — ссылки на группы в шапке; настройки открываются без фокуса в поле (слово владельца «чиним все», ревью п. 23, 25).

(1) Ответ из «Входящих» (поле многострочное с HD-157) раньше склеивался: на границе доверия `notificationAction` переводы строк становились пробелами. Теперь `replyText` переводит любой перевод строки (`\r\n`, `\r`, U+2028) в `\n`, остальные управляющие символы (ESC, Tab, DEL, NUL) выбрасывает, обрезает пробелы и пустые строки по краям и длину до 2000 символов; текст уходит тем же путём, что `tabs_send`: вставкой (bracketed paste — `\n` не отправляет, ESC вырезан и не закроет вставку) и одним Enter. Ответ из баннера macOS однострочный, путь тот же. Поле ответа берёт высоту по числу набранных строк (до 6), не полагаясь на самоувеличение вертикального поля. (Проверочный запуск без активации держит поповер вне экрана, и SwiftUI там не перестраивает разметку вовсе — поле «в одну строку» в прошлой проверке, вероятно, отсюда; рост в живом активном окне таким запуском не проверить.) (2) «Оформление» остаётся одной страницей (HD-109); справа в шапке страницы — простые small-кнопки «Тема · Редактор · Цвета · Шрифт · Отступы и перенос · Вид», клик прокручивает страницу к группе (верх группы — к верху страницы). Не помещаются в шапку (узкое окно) — скрыты целиком. (3) Окно настроек при открытии не ставит каретку в первое поле («Внешний редактор»): первый ответчик снимается; поле — по клику или Tab. **Отвергнуто:** разбить «Оформление» на страницы — противоречит HD-109; поле-фильтр настроек — для шести групп хватает ссылок; ответ построчно с Enter после каждой строки — агент получил бы несколько сообщений.
