# HD-025 — 2026-10-18 — Интерфейс `GhosttyBridge`:

`@MainActor final class GhosttyApp { static let shared; func start() throws }`; `@MainActor final class TerminalSurfaceView: NSView { init(spec: LaunchSpec); var onTitleChange: ((String) -> Void)?; var onBell: (() -> Void)?; var onDesktopNotification: ((String, String) -> Void)? /* title, body */; var onChildExit: ((Int32) -> Void)? /* -1 = код неизвестен */; func setVisible(_ visible: Bool) /* ghostty_surface_set_occlusion */; func sendText(_ text: String) /* bracketed paste, не выполняет команду */; func sendEnter() /* новое: ghostty_surface_key, keycode 36 */; func screenText() -> String? }`. Колбэки сразу копируют C-строки и вызываются на main. Почему: подтверждено спайком, `sendEnter` нужен для `hangar tabs send`/MCP. Отвергнуто: `sendText("...\r")` — вставка Enter не отправляет.
