# HD-135 — 2026-11-05 — Статусы: «готово» просмотрено или нет, формы точек, время ожидания, рамка панели сплита, спокойнее diff (пакет UX, одобрен владельцем; исследование UX п. 1, 2, 3, 6, 10; спека дизайн-системы §2.5–§2.9, §3.3, §3.5, §3.13, §3.16, §3.20; DESIGN.md; уточняет HD-067, HD-112, HD-130).

(1) «Готово» новое, пока его не видели: `LeafStatus.unseen` ставит каждый done, снимает показ листа на экране (выбранный чат — активная вкладка, если её не закрывает diff или История, и открытый «Терминал»; окно видно и приложение активно) — отмечаются только листы, которые *появились* на экране, поэтому «Отметить непрочитанным» (меню чата, только при просмотренном «готово») держится, пока чат не покинут, а уход из приложения и возврат снова показывают видимое. Done, пришедший на видимый лист, сразу просмотрен; «Убрать»/«Очистить» во входящих — тоже просмотр. Просмотренное «готово» — полое кольцо `done`, во «Готово недавно» не показывается (запись не удаляется — «Отметить непрочитанным» возвращает её с текстом). Хранится в памяти вместе со статусами: сами статусы после перезапуска не восстанавливаются, хранить «просмотрено» отдельно незачем. Фильтр «только ждущие» (HD-067) и Dock-бейдж не меняются: «готово» не требует действия. (2) Формы точек всегда (не только при системной настройке): «работает» — кольцо с заполненной половиной (◑; четверть из исследования на 6–8 pt читается как точка), «готово» — сплошная / полое кольцо `done` после просмотра, «простой» — сплошная точка `idle` в .75 размера (не кольцо: полое кольцо — та самая «пустая радиокнопка», от которой ушли в HD-130; замечание владельца на ревью); «ждёт», «ошибка», «на лимите» — сплошные (у строки слово, у «ждёт» ещё ореол). Системное «Различать без цвета» делает ошибку ромбом — иначе на вкладке и плитке рейки она отличалась бы от «готово» только красным; «Увеличить контраст» — `text3` → `text2`, `line` → `line2`, `idle` → `text2`. Оба флага читаются из `NSWorkspace` при запуске и по `accessibilityDisplayOptionsDidChangeNotification`, перерисовка — как при смене темы. На выбранной строке «простой» — точка `onAccent` .4 без обводки (HD-130), просмотренное «готово» — кольцо `onAccent` без обводки, остальные — с белой обводкой, как в HD-130. VoiceOver называет состояние словами («готово, не просмотрено», «ждёт ответа 4 мин»). Анимаций не добавлено. (3) Ждущая строка: тултип «ждёт 4 мин · codex · <текст запроса>» (самый старый запрос чата, текст — как в уведомлении), через 5 мин слово в строке — «ждёт 12 м» / «ждёт 2 ч». Пересчёт — `TimelineView` с расписанием «раз в минуту, только пока строка ждёт» (`MinutesWhile`); остальные строки получают одну запись и не просыпаются — правило энергии «в простое ноль таймеров» соблюдено. (4) Рамка 1 px `waiting` / `failed` вокруг панели сплита, которая ждёт или с ошибкой, включая её заголовок; у одиночной панели вкладки рамки нет (вся вкладка и есть эта панель, её точка уже на вкладке). Рамка не снимается фокусом: она показывает, какая панель спрашивает, а не где курсор; уходит вместе со статусом. Без анимации. (5) Diff: фон строк ≤ .10 (`diffAdd`/`diffDel`: Navy .08/.10, Dark+ .10/.10, Графит .08/.10), изменённые символы — `gitA`/`gitD` .28 поверх (было .12), штриховка пустой стороны — `line` .5. Тест: шаг символов над строкой ≥ 1.4 по контрасту, `text1` на символах ≥ 4.5 во всех темах. Палитра редактора Dark Modern (копия VS Code) не тронута; новых режимов diff нет.
