Что изменилось

  • Настройки — в одной карточке строками «подпись → значение», без капса и разъезжающихся подписей.
  • От ветки — выпадающий список с поиском: сначала remote (по умолчанию origin/HEAD), потом локальные ветки. Последний выбор запоминается для проекта.
  • Новая ветка подставляется из названия, но её можно отредактировать.
  • Выбора агента в окне нет: всегда стартует агент по умолчанию (claude). Сменить его можно в настройках, а другие агенты добавляются вкладкой через +.
