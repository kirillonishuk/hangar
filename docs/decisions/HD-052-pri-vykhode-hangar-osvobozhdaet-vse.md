# HD-052 — 2026-10-23 — При выходе Hangar освобождает все surface.

`applicationWillTerminate` последним шагом вызывает `TerminalSurfaceView.freeAll()` → `ghostty_surface_free` для каждой вкладки: Ghostty шлёт SIGHUP группе процесса и повторяет, пока `login` не выйдет. Раньше при выходе полагались только на hangup при закрытии pty; вкладка, созданная прямо перед выходом (`login` ещё стартует), его пропускала, и `login → zsh` оставались жить с родителем 1. Выход ждёт завершения детей (обычно доли секунды). Перед этим запускается сторож: через 3 с `_exit(0)`, чтобы ребёнок, игнорирующий SIGHUP, не повесил выход (состояние к тому моменту сохранено, сервер остановлен). Отвергнуто: свой kill по pid — Ghostty уже делает это при закрытии вкладки.
