Hangar — темы приложения v1

Запрос: «давай и тему самого приложения тогда переделаем» — после того как редактор получил подсветку VS Code Dark+. Раскладка — ровно утверждённый redesign-v1; меняются только цвета. Синтаксис кода во всех темах — Dark+ (одни и те же цвета токенов, как в VS Code пользователя); от темы зависят фон редактора, номера строк, текущая строка, выделение, фон diff. Внутри каждого окна открыт поповер «⋯» сессии; под окном — лист «Новая сессия», полная таблица токенов, палитра ANSI для терминала и проверка контраста WCAG AA (считается в странице из тех же токенов).

АкцентКак в темеСистемный
  • Где. Настройки → Оформление → Тема: четыре карточки с мини-превью (выбор — рамка accent). Пишется в конфиг Hangar: theme = "dark-plus" | "graphite" | "navy" | "dark-modern". По умолчанию для новых установок — Dark+; у существующих пользователей остаётся Navy, пока не выберут другую.
  • Живое переключение, без перезапуска. Theme перестаёт быть набором статических констант: токены — поля значения Palette, текущая палитра — один @Observable ThemeStore.current; SwiftUI-вью читают её и перерисовываются сами, AppKit-части (окно, NSPopover, разделители) подписываются на одно уведомление themeDidChange. Смена — без анимации (одним кадром), чтобы не было «переливания» и прыжков.
  • Терминал. Фон терминала = termBg темы — Hangar передаёт его в Ghostty поверх конфига пользователя (как сейчас, решение #36) и на смене темы вызывает обновление конфига приложения GhosttyKit для всех surface, так что открытые терминалы меняют фон сразу. «Фон терминала: Из Ghostty» = существующее terminal_background = "theme": тогда фон берётся из конфига Ghostty пользователя, а тема Hangar его не трогает. Палитра ANSI: если в конфиге Ghostty пользователя есть palette/theme, она побеждает; иначе подставляется палитра темы Hangar (таблицы ниже). Файл конфига Ghostty Hangar не меняет никогда.
  • Редактор и diff. Monaco получает по теме свою defineTheme (база vs-dark + правила токенов Dark+ одинаковые во всех темах; от темы — editor.background, editorLineNumber.*, editor.lineHighlightBackground, editor.selectionBackground, editorIndentGuide.*, diffEditor.inserted/removedLineBackground, editorGutter.*). На смене темы мост шлёт monaco.editor.setTheme(id) во все открытые редакторы — без перезагрузки страницы, курсор и undo сохраняются.
  • Что не зависит от темы. Цвета синтаксиса (Dark+), логотипы агентов (Claude #d97757), светофор, раскладка и размеры.
  • Только тёмные. Светлых тем в v1 нет (DESIGN.md: «только тёмная тема в v1»); системный режим не отслеживается.
