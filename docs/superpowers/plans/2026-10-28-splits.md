# Hangar — сплиты: любые панели, перетаскивание, заголовки панелей — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Делить экран на панели любого вида (Claude, Codex, Терминал, Редактор), собирать вкладки в сплит перетаскиванием и выносить панели обратно, у каждой панели — свой заголовок с меню; всё сохраняется в `state.json`.

**Architecture:** Чистые операции дерева в `Workspace` (`mergeTab`, `moveLeaf`, `detachLeaf`, панель-«выбор» как `LeafKind.choose`, `Leaf.customTitle`) с юнит-тестами. Листья сохраняют `id`, поэтому `TerminalArea` переносит те же `LeafView` (и их surface Ghostty / `EditorPane`) между контейнерами вкладок без перезапуска. Перетаскивание: жесты остаются там, где они есть (SwiftUI `DragGesture` вкладки и нового заголовка панели, координаты окна), а решение «куда бросить» и подсветку зон делает один оконный `PaneDragController` (AppKit-оверлей над панелями + линия-вставка в полосе вкладок) через чистую функцию `resolveDrop`. Редактор в сплите: `EditorHost` держит до 2 страниц Monaco, видимые редакторы вкладки получают разные страницы.

**Tech Stack:** Swift 6, Swift Testing, AppKit + SwiftUI, WebKit (Monaco), GhosttyKit через `GhosttyBridge`, macOS 14+.

**Spec:** `docs/superpowers/specs/2026-10-28-splits-design.md` (целиком). Контекст: `docs/decisions.md` #39 (реестр `Action`), #41/#55 (восстановление сплитов), #43 (статусы, hooks), #54 (заголовок панели, `DragGesture`/`dropIndex`, `splitNeighbour`), #64 (SSH-терминалы — только шелл), #81/#83 (Monaco, файл = вкладка, один `EditorHost`), #93 (поле ввода), #99 (пустая сессия, кнопки видов). ## Review Focus

1. **Перенос живой surface между контейнерами вкладок.** `TerminalArea.sync()` удаляет контейнер исчезнувшей вкладки-источника *до* того, как целевая вкладка переподвесит её лист → `LeafView` с surface на мгновение вне окна (пустой терминал, сброс Ghostty). Ожидание: тот же `LeafView`, ни одной потери окна. Тест: Task 3 `mergedLeafViewNeverLeavesWindow`.
2. **Статус агента после переноса.** Хуки агента несут `HANGAR_TAB_ID` момента запуска, а `liveLeaf(_:tab:)` требует, чтобы лист был в этой вкладке → после слияния/выноса статус и «Входящие» молча замирают. Ожидание: события от прежней вкладки этого листа принимаются, от чужой — нет. Тесты: Task 3 `hookFromFormerTabIsApplied`, `hookFromUnrelatedTabIsRejected`.
3. **Бросок вкладки на саму себя, на diff, в вкладку-просмотр.** Перетаскивают активную вкладку на её же панели; бросают при открытом diff; сливают агента в вкладку-просмотр (#83), а следующий клик в Files заменяет её `root` целиком и убивает агента. Ожидание: отмена в первых двух случаях, цель перестаёт быть просмотром в третьем. Тесты: Task 2 `mergeIntoPreviewTabPinsIt`, `mergeIntoItselfIsRejected`; Task 6 `dropOnOwnPanesIsNil`, `noPaneTargetsWhileDiffShown`.
4. **Закрытие фокусной панели, пока агент работает.** ⌘W в сплите теперь закрывает панель, и привычное нажатие убивает работающего агента без вопроса; ⌘W с фокусом в TERMINAL должен по-прежнему сворачивать её. Ожидание: подтверждение при `working`, вопрос о несохранённом у редактора, drawer — как раньше. Тесты: Task 5 `closePaneWithWorkingAgentAsks`, `closeKeyRouteTable`.
5. **`state.json` с панелью-«выбором».** Выход, пока открыта панель-выбор; или откат на старую версию, которая не знает `kind: "choose"` и сочла бы весь файл битым (переименовала бы в `.bak`). Ожидание: в файл «выбор» не попадает никогда, при чтении убирается, вкладка только из «выбора» исчезает. Тесты: Task 1 `savedStateHasNoChooser`, `loadPrunesChooserOnlyTab`.
