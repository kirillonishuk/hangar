# HD-116 — 2026-10-30 — Имя чата при пустом названии; лист «Новый чат» (этап 9 дизайн-системы, спека `specs/2026-10-30-design-system.md` §3.14; решение владельца, дополняет #113).

Название можно не заполнять: имя чата — первая непустая строка задания для агента (пробелы схлопнуты, до 40 знаков, обрезка по слову; одно длинное слово — жёстко), а без задания — «Чат N» / "Chat N", где N — наименьший номер, не занятый чатом проекта с таким именем (считаются все чаты проекта в состоянии, включая архив). Ветка копии следует за этим именем так же, как за названием (#48), пока её не правили руками. Лист: «Где работать» — две опции-радио вместо переключателя Worktree; «В папке проекта» показывает живую ветку папки проекта (`Git.head()` при открытии листа, тот же источник, что у `BranchModel`), «В отдельной копии» без коммитов или без соединения недоступна (.4 один раз, через `.disabled`, без второй прозрачности; причина — текстом в опции). Поля копии видны только при выбранной копии (раньше — неактивные строки с двойным затемнением). Задание для агента свёрнуто по умолчанию; ↩ в «Названии» или «Ветке копии» раскрывает его и ставит туда курсор. «Где работать» — одна остановка Tab (радиогруппа: ←/↑ — папка, →/↓ — копия, пробел переключает; для VoiceOver — радиокнопки), свёртка — тоже (пробел/↩), обе без «Полного доступа с клавиатуры». Имя из задания — первая строка с видимым текстом: без маркеров markdown в начале (`#`, `>`, `-`, `*`, `+`), без строк-ограждений кода и невидимых символов (zero-width space, BOM; ZWJ/ZWNJ остаются); маркер — только целое слово из `#>*-+` («-1 bug», «**жирный**» не трогаются); набранное название только обрезается по краям; «Чат N» считается в момент создания (чат мог появиться из другого окна). «esc — отмена» не пишется (Esc по-прежнему отменяет); ⌘↩ — в тултипе «Создать чат». «Обновлено N мин назад» перешло в тултип ↻. **Не принято из макета:** префикс `hangar/` у ветки копии — именование веток по #48 не менялось. Дополнение (2026-10-30, слово владельца): чат с именем «Чат N» помечен `autoNamed` и получает имя от первого запроса своего агента — первая видимая строка `prompt` из `UserPromptSubmit` по тем же правилам (≤ 40, без markdown и невидимых), только от агента вкладки (hook из `--settings`, #119, работает и без интеграции); слэш-команда или запрос без текста — заголовок терминала агента, если тот его задал (не «Claude Code» — это заголовок самого claude), иначе ждём следующего запроса. Один раз: после этого и после любого переименования пользователем флаг снят; ветка копии не переименовывается.
