# HD-120 — 2026-10-30 — Окно на macOS 26: тулбар не зависит от safe area; лимиты — всегда оба окна; рейка спокойнее (правки по живому окну v0.9.0; спека `specs/2026-10-30-design-system.md` §3.1, §3.3; дополняет HD-115).

Сборка с SDK 26 (релиз) получает от окна полосу заголовка 66, а не 52: SwiftUI сдвигал наш тулбар на 14 вверх (название, ветка, колокольчик выше светофора). Хосты, которые мы раскладываем сами (тулбар, вкладки, сайдбар, инспектор, «История», тост, пустые состояния, заголовки панелей, выбор вкладки, дифф), теперь без safe area (`safeAreaRegions = []`); радиус углов окна — системный (у окна с тулбаром на macOS 26 — 26), своей обрезки нет. Локальный `swift build` (новый бэкенд) пишет в бинарник SDK 14 — окно рисуется по-старому (углы 12, полоса 52), поэтому вид окна проверяется сборкой `--build-system native`. Лимиты: тик статус-лайна без окна (Claude Code не всегда шлёт `five_hour`) не стирает последнее известное значение — окно 5 ч остаётся до своего сброса, после него хранится как 0 (и снимает «лимит»); окно без времени сброса не переносится; «лимит до …» берёт только окна, чей сброс впереди; в сайдбаре у агента две подписанные строки «5 ч» и «нед» с процентом каждой, в поповере 5 ч и неделя есть всегда, без данных — «—» / «нет данных»; поповер блока открывается вверх, не на полосу «Терминал». Рейка: плитки 20 (проекты — контур `line2`, чаты — заливка `hover2`), между ними 8, точка — на углу плитки с кольцом цвета того, что под ней; выбор и наведение — квадрат 28 (`selected` / `hover`), не полоса `selectedFocus`; разделитель секции 16.
