# HD-147 — 2026-11-06 — «Просмотрено» в diff и «Код · Просмотр» для HTML / Markdown / SVG

**«Просмотрено».** Чип в заголовке diff файла из «Изменений» и клавиша ⌥V (keyCode 9 + ⌥, работает в русской раскладке; без ⌥ буква нужна Monaco) отмечают файл и открывают следующий непросмотренный по порядку списка, по кругу. Отметка хранится на чат: путь → отпечаток `база diff | вид изменения | исходный путь | размер | mtime` (на сервере, где нет stat, — числа строк, у неотслеживаемого — без них, иначе поздний подсчёт сбросил бы свежую отметку). Отпечаток не совпал — отметки нет: файл, изменённый после просмотра, снова непросмотрен; ⌥B (другая база) — другой diff. Проверка стоит один stat на отметку, не на файл. Строки отмеченных — галочка вместо иконки и прозрачность `.4`; прогресс — «просмотрено N» над списком, «N из M» в тултипе (M уже на счётчике «Изменения», HD-106). Хранение — в памяти `AppState`: переключение чатов переживает, перезапуск — нет; архив чата отметки убирает.

**«Код · Просмотр».** Сегмент в заголовке diff и редактора у HTML / Markdown / SVG проекта на этом Mac; выбор один на все файлы, сохраняется в `state.json` (`renderPreview`, как `diffInline`). Diff — «Было» из `git cat-file` той же базы (у коммита — родитель), «Стало» — рабочий файл или файл коммита, раскладка как у картинок HD-142; редактор — страница поверх Monaco (буфер не трогается, показывается файл с диска, обновляется тем же FSEvents-наблюдателем). Markdown — `AttributedString(markdown:)` (GFM системы), блоки обратно в теги, сырой HTML остаётся текстом; SVG — `<img>` из data-URL (как картинка: без скриптов и загрузок).

**Безопасность (граница доверия — файлы, которые пишет агент).** WKWebView с выключенным JavaScript, неперсистентным хранилищем и списком блокировки сети редактора (http/https/ws/ftp); если список не скомпилировался — страница не показывается. Страница грузится данными с базовым адресом `hangar-preview://page/<папка>/`: относительные файлы отдаёт свой обработчик схемы только изнутри корня проекта (после разрешения симлинков, без `..`), не больше 5 МБ; доступа к file:// у страницы нет. Разрешена только загрузка, начатая Hangar, и фреймы той же схемы; остальные переходы отменяются, http(s)-ссылка по явному клику открывается в браузере по умолчанию.

**Почему.** Владелец ревьюит много файлов агента и макеты HTML: нужен прогресс «что уже смотрел» и вид страницы, а не только её код. Всё — системные WebKit и Foundation, без зависимостей.

**Ограничения (shortcut).** Проект на сервере — без «Код · Просмотр» (у раннера нет байтового канала, как HD-142). Относительные файлы старой стороны берутся из текущей папки, не из git. Отметки «Просмотрено» не переживают перезапуск — менять, если попросят.

**Отвергнуто:** `loadFileURL`/file://-база — даёт странице чтение папки и её соседей, а по симлинкам — и дальше; рендер Markdown в Monaco (marked внутри бандла) — нужен JS на странице; отметка по одному хэшу diff — у неоткрытых файлов diff не загружен, список не смог бы их приглушить; хранение отметок в `state.json` — лишняя запись на каждый клик ради редкого перезапуска.
