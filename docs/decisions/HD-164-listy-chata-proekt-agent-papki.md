# HD-164 — 2026-11-13 — Листы чата: проект и агент выбираются в «Новом чате», «Задание» помнит, раскрыто ли, у листов одна раскладка, «Путь» сервера подсказывает папки (слово владельца «чиним все»; заменяет часть HD-009 про выбор агента, уточняет спеку дизайн-системы §3.14).

Аудит листов: (1) ⌘N открывал «Новый чат» для непредсказуемого проекта (выбранного чата, иначе последнего в списке), а сменить его в листе было нельзя. Теперь проект в заголовке — всплывающая кнопка (§3.9) со списком проектов; смена делает новую модель листа, «Название», «Задание», его раскрытость и агент переносятся. По умолчанию — проект выбранного чата, иначе проект последнего созданного чата, иначе последний добавленный (`WorkspaceState.newChatProjectId`; чаты без проекта и ssh-входы не в счёт). (2) «Задание для …» было свёрнуто всегда, фокус — в необязательное «Название». Теперь лист помнит, оставили ли «Задание» раскрытым (`newChatPromptOpen` в state.json, как другие флаги вида); раскрыто — фокус в него. (3) Агент: в «Новом чате» рядом с «Названием» — сегмент «Агент» Claude / Codex (по умолчанию — агент из настроек), подпись «Задание для Claude/Codex» следует ему. Это **заменяет** в HD-009 «в листе новой задачи выбора агента нет»: агент по умолчанию по-прежнему задаётся в настройках. (4) Одна раскладка листов-форм (§3.14): «Новый чат», «Подчат», «Удалённый проект», «Подключиться к серверу» — поля без рамки-карточки, подпись над полем, пояснение или ошибка строкой под ним, группы через 16; «Где работать» в «Подчате» — те же две опции-карточки, что в «Новом чате» («В папке чата» — та же папка и ветка); «Что сделать» растёт, как «Задание», до 12 строк; подвал всех листов — 20 под телом, линия `line2` во всю ширину, кнопки справа. Карточки остаются у листов-настроек («Настройки проекта») и отчёта сервера. (5) «Удалённый проект»: когда сервер подключён, ▾ у «Путь» (или ↓ в поле) показывает папки того, что набрано, по одному уровню — как дополнение пути; выбор подставляет `папка/` и открывает следующий уровень. Список — тем же скриптом, что Файлы удалённого терминала (`remoteListScript`), через соединение сервера; скрытые папки — только когда набрана точка. До подключения ▾ неактивна, причина — в подсказке. **Отвергнуто:** меню папок на каждое нажатие клавиши — панель меню забирает фокус у поля; отдельный лист выбора папки сервера — дольше, чем дополнение.
