# HD-040 — 2026-10-19 — Нижняя панель TERMINAL (Task 6c, #37):

у задачи `drawer {leaf?, visible, height}` (старый state.json без ключа читается с умолчаниями). Шелл панели — обычный `Leaf(kind: .shell)` в cwd задачи, его хостит тот же `LeafView` (перезапуск, полоса ошибки). Surface создаётся при первом раскрытии и не пересоздаётся; свёрнутая панель — `setVisible(false)`. ⌃` (keyCode 50) и клик по полосе — `Action.toggleDrawer`; раскрытие переводит фокус в шелл, сворачивание из шелла возвращает фокус во вкладку. Выход с кодом 0 сворачивает панель и удаляет лист. Высота: модель ≥ 120, UI — до 70% области; перетаскивание верхней кромки, сохранение на отпускании.
