# HD-142 — 2026-11-05 — Картинки в diff и редакторе вместо «Бинарный файл»

Бинарный файл, который декодирует `NSImage` (png, jpeg, gif, webp, heic, tiff, bmp, ico, pdf, svg — решает попытка декодирования, не расширение), показывается картинкой. Diff: добавлен — новая, удалён — старая, изменён — обе с подписями «Было» / «Стало» и размером в пикселях; старая сторона — `git cat-file blob <база>:<путь>` (та же база, что у текстового diff; у коммита — его родитель), новая — рабочий файл или файл коммита. Редактор (открытие из дерева, ⌘P): картинка поверх сообщения Monaco, с размером в пикселях и файла, только просмотр. Чтение и декодирование — вне главного потока; больше 50 МБ — прежнее сообщение. Вписывается в панель, не крупнее своего размера, фон `bg0` (без шахматки).

**Почему.** Пользователь открывал изменённые макеты (`*.png`) и видел только «Бинарный файл»; картинки — частый артефакт агентов (рендеры макетов, скриншоты). Системный `NSImage` уже умеет все нужные форматы — новой зависимости нет.

**Ограничение (shortcut).** Только локальные проекты: `Runner` и `EditorIO.remote` отдают stdout строкой UTF-8, байты картинки на сервере теряются; для проекта на сервере остаётся «Бинарный файл». Менять, когда понадобится — дать раннеру байтовый канал.

**Отвергнуто:** показ картинки внутри Monaco (data-URL в странице) — гонять до 50 МБ base64 через мост ради просмотра; шахматка под прозрачным — не просили; выбор по расширению — не ловит svg/heic без расширения и ошибается на битых файлах.
