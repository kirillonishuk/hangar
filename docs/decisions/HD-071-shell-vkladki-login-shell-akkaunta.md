# HD-071 — 2026-10-24 — Шелл вкладки — логин-шелл аккаунта (`getpwuid`), zsh-вкладка получает shell integration Ghostty.

Hangar брал шелл из `$SHELL` своего процесса, то есть того, кто его запустил: при запуске из bash-окружения (`SHELL=/bin/bash`) вкладка «Терминал» была bash (`host:proj user$`), и zsh-плагины пользователя (подсветка, автоподсказки, fzf, zoxide) не грузились; login(1) внутри вкладки при этом ставит `SHELL=/bin/zsh` из passwd. Теперь `resolveUserShell`: `pw_shell`, затем `$SHELL`, затем `/bin/zsh` — как Ghostty.app. Ghostty внедряет свою zsh-интеграцию (ZDOTDIR) только во внешний `zsh -l -i -c`, его `.zshenv` восстанавливает ZDOTDIR, и интерактивный zsh вкладки оставался без неё; теперь перед ним ставится ZDOTDIR интеграции (свой ZDOTDIR пользователя передаётся через `GHOSTTY_ZSH_ZDOTDIR`), только если во внешнем шелле есть `_ghostty_state` (интеграция не выключена). Следствие: заголовок zsh-вкладки — путь/команда от интеграции, как в Ghostty.app. TERM/TERMINFO не причина: Ghostty выставляет их сам из ресурсов бандла, `term = xterm-256color` — из конфига Ghostty пользователя.
