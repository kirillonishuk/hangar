# HD-087 — 2026-10-27 — Открытые терминалы перекрашиваются при смене темы; QA v0.2.0 (уточняет HD-085).

Причины «открытые терминалы сохраняют прежний фон» в коде нет: `ghostty_app_update_config` раздаёт новый конфиг всем surface (`Surface.updateConfig`), а тот повторяет те же слои — файл умолчаний Hangar, файлы пользователя с его `theme` (тема ложится под всё), файл `overrides` с фоном последним. Проверено вживую (DEBUG, изолированный HOME/XDG с поддельным конфигом Ghostty: `theme` по имени и по пути, `background-opacity = 0.95`, копия реального конфига): «как тема» перекрашивает открытые вкладки, скрытые вкладки и сессии, TERMINAL и Claude-вкладки; «из Ghostty» оставляет фон пользователя; переключение режима фона тоже живое. Вероятный источник прежнего наблюдения: окно, закрытое другими окнами, на паузе рендера и показывает старый кадр, пока снова не станет видимым. Shortcut-комментарий убран; слои вынесены в `GhosttyApp.layers` и проверяются тестом через сам libghostty (`GhosttyLayersTests`: тема пользователя против «как тема» / «из Ghostty», конфиг без фона). Отладка: `HANGAR_DEBUG_BEHIND=1` держит окна позади остальных, команды `termbg`, `window back`. QA трёх тем × ru/en: строка лимита при достигнутом лимите без данных окон показывает 100% и пустые полоски — теперь полоски заполнены; заголовок «Worktree» в настройках проекта — через L10n.
