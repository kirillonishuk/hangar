Рекомендация — A «Тихие рамки». Кнопка отличается от подсказки формой (рамка), а не только цветом, поэтому серые тексты перестают быть двусмысленными; в плотном инспекторе и Inbox не появляется столбик плашек; акцент остаётся для одной главной кнопки на строку. Из B стоит взять чипы фильтров поиска (значение видно сразу) — они уже есть в Git.
