# HD-145 — 2026-11-05 — Лимиты: «обновить» только у Codex, у Claude — подсказка «обновляется, когда агент делает ход» (сужает поведение кнопки ↻ из спеки; HD-012 остаётся)

Владелец нажал «обновить» в поповере лимитов — ничего не изменилось. Лимиты Claude приходят только через строку состояния, когда агент делает ход (HD-012); запрос по требованию через недокументированный OAuth-endpoint отвергнут и остаётся отвергнутым (владелец подтвердил). Значит, для Claude кнопка ничего не делала.

Теперь: у секции Claude кнопки нет; под её окнами подпись `caption` `text3` «обновляется, когда агент Claude делает ход» (тултип — почему и что запросить нельзя). «обновить» есть только в секции Codex (единственный источник, который можно прочитать по требованию), строкой под её окнами; когда в поповере один Claude — кнопки нет совсем. Клик виден: пока идёт чтение — спиннер и кнопка неактивна, после успеха «обновлено только что», после ошибки — строка `failedText` «не удалось обновить». Нижняя строка поповера — только подсказка ⇧⌘L.

**Отвергнуто:** оставить кнопку у Claude (обманывает); читать лимиты Claude через OAuth-endpoint (HD-012).
