Hangar — кликабельные элементы v2

Основа — вариант B из v1 («Заливки»), переделанный так, чтобы он выглядел частью приложения, а не набором чужих кнопок. Рядом — одна альтернатива для сравнения. Оба варианта показаны в шести местах: инспектор (Changes и Поиск), «Входящие», «Сессии», пустая сессия и тост. Всё нарисовано так, как эти места выглядят сейчас в Dark+. Курсор-рука — там, где показано наведение. Цвета только из ThemePalette, новых токенов нет.

Рекомендация — B′ «Мягкие заливки».

Эти заливки уже есть в приложении: button у вторичной кнопки VS Code, hoverStrong у «+ Новая сессия», accent 14 % у чипа ветки в Git. Значит, кнопка читается как кнопка, но новой формы не появляется. Акцентная заливка — одна на строку («Разрешить»). Остальные действия строки появляются только при наведении, поэтому столбика плашек нет. Режимы показаны теми же чипами, что фильтры Git: выбранный виден сразу, без тултипа. Клавиши (⌥B, ⌘Z, ⌘T) показаны только в тултипе «Действие — клавиша», как везде в приложении.

У C самый «VS Code» вид, и он самый тихий. Но у главного действия нет заливки, и при беглом взгляде «Разрешить» снова похоже на подпись. Из C в B′ стоит взять только раскрывающийся список режима: он нужен там, где для двух чипов не хватает ширины.
