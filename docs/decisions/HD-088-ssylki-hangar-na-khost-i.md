# HD-088 — 2026-10-27 — Ссылки `hangar://` на хост и вид «Сессии», только полные UUID, тост вместо тишины (дополняет и ужесточает #66; паритет с Pane `links_create`, pane-parity п. 9).

Новые формы: `hangar://sessions/<id проекта>` — вид «Сессии» (⌘Y) этого проекта; `hangar://host/<хост>` — хост из SSH HOSTS. Ссылка на хост показывает его терминал («<host> · терминал»), иначе раскрывает его проекты и выбирает сессию одного из них (выбранная, если она уже на этом хосте); хост только из ssh config без терминала и проектов — без изменений. Любая ссылка, кроме `sessions`, закрывает вид «Сессии», даже если цель — уже выбранная сессия. Ни ссылка на хост, ни другие не открывают ssh, не подключают хост, не создают и не удаляют ничего. Граница доверия (URL открывает любая страница или приложение), `HangarLink(url:)`: известный вид, без user/password/port/query/fragment, путь берётся percent-encoded (`%` не проходит, ничего не декодируется); у task/tab/project/sessions — ровно полный UUID (36 символов, `UUID(uuidString:)`): префиксы и имена из #66 в ссылках больше не принимаются (они остаются в CLI/MCP, которые печатают полный id); у host — 1…255 символов ASCII `[A-Za-z0-9._@-]`, не с `-` и без `@-` (не похоже на флаг ssh), имя без смены регистра. Хост с другими символами (IPv6, `%`) ссылки не получает (`shortcut:`), `links_create` — ошибка `bad_params`; ссылка на хост, которого нет в SSH HOSTS, — `not_found`. Неверная ссылка или пропавшая цель — тост «Ссылка никуда не ведёт: её цели в Hangar нет» (тот же тост, что «Сессия в архиве», без «Отменить», `ArchiveUndo.show(message:)`), окно выходит вперёд, больше ничего не меняется; лог как раньше. CLI `hangar link host|sessions <ref>`, MCP `links_create` с `kind: host|sessions`. «Скопировать ссылку» добавлен в меню проекта (реестр действий, #39) и в меню строки хоста. Имя вида `sessions` (вид «Сессии») рядом с `link session` (сессия = `task`, #73) — как в интерфейсе. Отвергнуто: ссылка на хост как вход по ssh (выполнение команды из ссылки), ссылка на «Сессии» без проекта (вид всегда показывает проект), стабильный UUID хоста (у хостов из ssh config его нет; имя и есть их id в модели).
