# HD-056 — 2026-10-24 — Иконки v2: свой линейный набор вместо SF Symbols; один формат тултипа; новые клавиши.

По слову пользователя (утверждён `icons-v2.html`). 32 глифа рисуются в коде (`NSBezierPath`, сетка 16, линия 1.5 pt при любом размере, круглые концы и стыки, template), путь — из `<symbol>` макета; логотипы claude/codex не меняются. Почему: один стиль и вес вместо смешанных SF Symbols. Отвергнуто: SF Symbols (разный визуальный вес, `pin.fill` — заливка) и SVG в бандле (линия масштабируется: 0.9 pt при 10, нужен бандл в тестах и `swift run`). Исправлены глифы не по действию: «Переподключиться» / «Отключиться» / «Проверить сервер» получили свои `reconnect` / `disconnect` / `checkServer` (раньше `refresh` / `close` / `sshHost`), «Открыть в Finder» — `finder`, diff-вкладка — иконка `diff` вместо текста «±», закреплённая задача — тот же `pin` цветом `textStrong`. Удалены `files`, `changes`, `search`, `pinned`; `newTask` → `add`, `worktree` → `branch`, `sidebarToggle` → `sidebarLeft`. `Theme.iconSize` 15 → 16. Тултип каждого кликабельного — «Действие — клавиша» (`L10n.help`), символы — `Shortcut.label` (⌃⌥⇧⌘) из одной таблицы `Shortcut.key`, по которой и сопоставляются клавиши. Новые клавиши (keyCode): `⌥⌘1`/`⌥⌘2` — инспектор на Files/Changes (Changes — только git), `⌥⌘R` — открыть выбранную задачу в Finder (только локальную), `⌥⌘C` — скопировать её путь; в контекстных меню они показаны. `⌘B` остаётся тихим синонимом `⌘0` (HD-039), в подсказках его нет. `⌘,` по-прежнему в меню приложения и в мониторе клавиш: убрать из монитора нельзя — при фокусе в терминале клавишу забирает привязка Ghostty по умолчанию `super+comma = open_config`, до меню она не доходит (`shortcut:` в `MainWindowController.perform`). Строка состояния показывает агента только если фокус активной вкладки на агенте; фокус на shell/Helix — без агентской части (раньше — «claude · неактивен» соседней панели или другой вкладки).
