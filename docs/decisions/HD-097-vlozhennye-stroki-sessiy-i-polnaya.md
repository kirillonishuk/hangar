# HD-097 — 2026-10-28 — Вложенные строки сессий и полная история «Сессий» (исправления, дополняют HD-074 и HD-076).

(1) Сайдбар: строки сессий под проектом не читались как вложенные — точка стояла на x шеврона. Теперь в развёрнутом виде точка и имя сессии проекта сдвинуты на `Theme.sessionIndent` = 16 (левый край точки под началом имени проекта); подсветка и рейка без изменений, сдвиг постоянный — при сворачивании ничего не двигается; закреплённые и архивные строки не сдвигаются. (2) «Сессии» теряли разговоры Claude: принадлежность решал *первый* записанный `cwd`, а у продолженных/перенесённых разговоров первая строка несёт другую папку (так пропадали в том числе переименованные через `/rename`); заголовок брался только из первого запроса, хотя Claude пишет имя `/rename` (`custom-title`) и своё (`ai-title`), повторяя их по ходу. Теперь разговор принадлежит папке, если любой его `cwd` — эта папка или папка внутри неё; `cwd` разговора — тот, по которому названа папка файла; заголовок — последний `custom-title`, иначе последний `ai-title`, иначе первый запрос (`shortcut:` переименование только в непрочитанной середине огромного файла не видно, пока Claude не допишет его снова). Сканируются и папки Claude для подпапок проекта (имя `<папка>-…`; подпапки, worktree самого Claude), локально и по ssh; сосед с тем же префиксом отсекается по `cwd`. Вид сканирует самую глубокую папку первой, чтобы worktree внутри проекта сохранял свою сессию; разговор из папки вложенного (более глубокого) проекта показывается только у него. `cwd` разговора — тот, по которому Claude назвал папку файла (там `--resume` его найдёт), даже если он вне проекта. Кэш разбора — по файлу (путь + mtime/размер), а не по папке скана: пересекающиеся папки читают файл один раз, у rollout Codex кэшируется и cwd из префикса. Заголовки очищаются от управляющих символов (C0/C1) и bidi-переключателей, обрезаются по 80 символам и 160 скалярам. Удалённая выборка — пачками по 100 (≈ 19 МБ, ниже лимита вывода хоста 64 МБ; проверяется тестом). Codex по-прежнему только точная папка. Почему: жалоба владельца (вложенность не видна; переименованных сессий нет в «Сессиях»). Отвергнуто: полное чтение файлов ради редких переименований в середине.
