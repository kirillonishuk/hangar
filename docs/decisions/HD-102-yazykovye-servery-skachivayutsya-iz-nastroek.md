# HD-102 — 2026-10-29 — Языковые серверы скачиваются из Настроек (по слову владельца: «в настройках скачать нужные, если нет; что скачены — показывать что установлены»; дополняет HD-082, HD-090).

В комплект приложения серверы не входят. Настройки → Редактор → секция «Языковые серверы», строка на язык: TypeScript / JavaScript — только сведения (плашка «Из проекта», tsserver из `node_modules` проекта, HD-082); Python (pyright), Go (gopls), Rust (rust-analyzer) — плашка «установлен · PATH / проект / Hangar <версия> / Xcode» (полный путь — в подсказке) или «не установлен» (строчными, как остальные плашки) и кнопка «Скачать»; у скачанных Hangar — «Удалить»; Swift — только сведения: «установлен · Xcode» или «нужен Xcode». Пока идёт установка, вместо плашки — «Скачивание… N%» (rust-analyzer) или «Установка…» и «Отмена»; ошибка — текст `failedText` (хвост вывода инструмента, полный — в подсказке) и «Повторить». Статус считается при открытии страницы (тот же `LspMap.find`, корень проекта — видимая локальная сессия) и после установки/удаления; фоновых проверок и таймеров нет. Папка — `<папка состояния>/lsp/<имя>/` (`~/Library/Application Support/Hangar/lsp`; DEBUG: `HANGAR_LSP_DIR`, иначе от `HANGAR_STATE_DIR`). Порядок поиска (HD-090) получает Hangar-папку четвёртой: проект → PATH логин-шелла → обычные места (`~/.cargo/bin` …) → **Hangar** → `xcrun`: собственная установка пользователя побеждает скачанную Hangar. Способы: rust-analyzer — `GET https://api.github.com/repos/rust-lang/rust-analyzer/releases/latest` и ассет `rust-analyzer-aarch64-apple-darwin.gz` (на Intel — `x86_64`) через `Updater.fetch/download` из HD-086 (https и тот же список хостов на адресах ленты, ассета и всех редиректах; тег — только `[A-Za-z0-9._+-]`, ≤ 40). Контрольной суммы GitHub для этих ассетов не публикует, поэтому проверяется то, что можно: `size` ассета из JSON известен и ≤ 100 МБ, загрузка обрывается, если Content-Length или полученные байты больше 100 МБ (`Updater.download(maxBytes:)`, `UpdateError.tooLarge`), размер файла равен объявленному; распаковка `/usr/bin/gunzip -c` в файл обрывается после 300 МБ (защита от gzip-бомбы); результат должен начинаться с Mach-O-сигнатуры (64-битный или универсальный); затем `chmod 755`, снятие карантина, версия — тег; pyright — `npm install --prefix <папка> --no-audit --no-fund pyright` с `npm` пользователя (PATH логин-шелла или обычные места; нет — вместо кнопки «Нужен Node.js»), версия из `node_modules/pyright/package.json`, сервер — `node_modules/.bin/pyright-langserver`; gopls — `go install golang.org/x/tools/gopls@latest` с `GOBIN=<папка>` (нет `go` — «Нужен Go»), версия из `go version -m`. Процессы — массивы аргументов без оболочки (пути с пробелами и `$(…)` остаются одним аргументом), с PATH логин-шелла, без sudo; отмена завершает процесс (и его группу). Окружение — только разрешённые переменные приложения (`HOME`, `PATH`, `TMPDIR`, `LANG`, `LC_*`, `USER`, `LOGNAME`, переменные прокси), без остального окружения приложения. npm: `--ignore-scripts --no-package-lock`, `npm_config_userconfig=/dev/null`, кэш во временной папке; go: `GOTOOLCHAIN=local`, `GOFLAGS=-mod=mod -modcacherw` (`-modcacherw` — чтобы кэш модулей можно было удалить), `GOMODCACHE` и `GOCACHE` во временной папке; временная папка кэшей удаляется после установки, так что `~/.npm` и кэши Go пользователя не пишутся. Версии pyright и gopls не закреплены (берётся последняя); gopls проверяет sumdb Go, у pyright — только TLS реестра npm. Установка идёт во временную скрытую папку рядом; прежняя установка Hangar сдвигается в сторону, новая ставится на её место, и старая удаляется только после успеха (не удалось поставить новую — старая возвращается); отмена или ошибка до этого ничего не трогают. В папке — метка `.hangar-lsp.json` с версией. «Удалить» удаляет только `<lsp>/<имя>` — настоящую папку (не симлинк) с меткой, чей realpath прямо внутри `<lsp>`. После установки или удаления `LspLanguages.serversChanged()`: кэш поиска сбрасывается, открытые файлы со статусом «нет языкового сервера» ищут снова и получают сервер без перезапуска и переоткрытия, процессы удалённого сервера заменяются (`rediscover`). Подсказка статуса «нет языкового сервера» упоминает Настройки → Редактор. DEBUG: `HANGAR_LSP_FEED` — тестовая лента (file:// разрешён только с ней), команда `lsp <пакет> running [доля] | failed <текст> | install | clear`. Проверка: юнит-тесты (порядок поиска с Hangar-папкой; источник статуса — проект / PATH / Hangar с версией / Xcode / нет; поиск npm/go; argv без инъекций; установка npm/go поддельными инструментами, ошибка инструмента без остатков; rust-analyzer из локальной file://-ленты с gunzip; список хостов и теги; лимит размера ассета, несовпадение размера, gzip-бомба, не-Mach-O; ограничение загрузки в `Updater.download`; окружение по списку и флаги npm/go; переустановка поверх прежней и её возврат при сбое замены; удаление только своих папок, отказ без метки и для симлинка; установка из модели сообщает редакторам и обновляет статус; отмена; файл со статусом «нет сервера» получает сервер после `serversChanged`) и живая DEBUG-проверка (dark-plus и navy: не установлен, установлен через поддельную ленту, скачивание, установка, ошибка). Формат ассетов настоящей ленты сверен одним запросом метаданных релиза; настоящие серверы при разработке не скачивались.
