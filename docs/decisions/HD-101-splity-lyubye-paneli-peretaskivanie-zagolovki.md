Сделано: в сплите любые панели (Claude, Codex, Терминал, Редактор); `Leaf.customTitle`; операции `mergeTab` / `moveLeaf` / `detachLeaf`, вставка с края (`SplitEdge`), `renameLeaf` — листья сохраняют `id`, их `LeafView` с surface или `EditorPane` переподвешивается и ни на миг не покидает окно (агенты не перезапускаются); хук агента из прежней вкладки перенесённого листа принимается (`formerTabs`), из чужой — нет, после ↩-перезапуска прежние вкладки забываются. ⌘D / ⇧⌘D — панель-«выбор» (Claude · Codex · Терминал ↩ · Редактор, Esc — закрыть; у терминала хоста #64 — сразу шелл). Заголовок у каждой панели разделённой вкладки (иконка, статус, имя, «⇱», «×», меню `Action` с целью `.leaf`, F2 / двойной клик — переименование). ⌘W в сплите закрывает фокусную панель, последнюю — с вкладкой; в TERMINAL — сворачивает, как раньше; подсказки ⌘W — по контексту (у «×» панели — только у фокусной). Перетаскивание (один механизм окна, без `NSItemProvider`, как #54): вкладка, утянутая из строки вниз, — на край панели (`mergeTab`); заголовок панели — на край другой панели (`moveLeaf`) или в строку вкладок (щель, `detachLeaf(toIndex:)`). Esc отменяет; бросок на свои панели, в середину, при открытом diff — ничего. Слияние в вкладку-просмотр (#83) её закрепляет. Решения по ходу (владелец не ответил — безопасный вариант, или по его слову): **(R1)** закрытие *вкладки* с работающим агентом тоже спрашивает (раньше — без вопроса; цена — лишний диалог); **(R2, слово владельца)** пустая сессия (#99) и «выбор» показывают «Продолжить» — до 5 последних бесед папки сессии из History (без открытых во вкладках), клик продолжает её (`--resume`) существующим путём; **(R3)** diff-вкладка и «Сессии» исключены на уровне жестов/действий, модель их не знает; **(R5)** подтверждение и когда агент *ждёт* (вопрос, разрешение), не только работает; **(R6)** без «пружинящих» вкладок: заголовок над строкой вкладок = вынос, перенос в другую вкладку — вынести и бросить вкладку на край (два жеста); **(R7)** вторая страница Monaco освобождается, только когда к ней не привязан ни один редактор, видимый или скрытый (undo сохраняется, нет вспышки; цена — лишний WKWebView, пока вкладка с двумя редакторами скрыта). Подписи зон — «Справа / Слева / Сверху / Снизу» (где окажется панель). Лимит — 2 редактора во вкладке: «Редактор» в «выборе» приглушён (тултип, звук, VoiceOver — неактивен), бросок, дающий третий, зон не подсвечивает. Панель-«выбор» — `LeafKind.choose` (а не `kind == nil`, компилятор находит все `switch`) и **никогда не сохраняется**: вырезается при записи и при чтении `state.json`, вкладка только из неё исчезает — откат на старую версию не сочтёт файл битым. Отклонения от спеки: «Редактор» в «выборе» открывает ⌘P-выбор файла (после #83 редактора без файла нет), уже открытый в сессии файл — фокус на его вкладку; `openInEditor` остаётся по #83, а не «в фокусной панели редактора» (§6 спеки писалась до #83); третий редактор не «открывает файл в фокусной», а не допускается. Попутно: Sessions «открыть в сессии» и «Продолжить» помечают лист для `--resume` внутри `perform` (иначе первый запуск начинал новую беседу) — тот же фикс пришёл в `main` в #25; панель, оставшаяся от закрытого сплита, снова получает autoresizing (`placeLeaf` из `main`). Полоса вкладок (слово владельца по ходу ревью): перестановка — сосед уступает, когда край перетаскиваемой вкладки (передний при движении влево, задний — вправо) проходит его середину, поэтому последняя позиция достижима; у поля переименования (вкладка, заголовок панели) — «×» отмены; файловая вкладка и панель редактора не переименовываются (имя — файл), F2 уходит в Monaco; файловая вкладка — во всю длину имени до 400, дальше усечение посередине; ведущий значок статуса агента в заголовке OSC отбрасывается; все вкладки одной высоты, линия `accent` повторяет скругление; сплит вкладки-просмотра её закрепляет (иначе клик в Files заменил бы сплит с агентом). Отвергнуто: `NSItemProvider` / системный drag&drop (как #54: один жест окна, которое знает геометрию строки вкладок и панелей), переносы между сессиями (разные папки/worktree), CLI/MCP-методы для сплитов (вне рамок, §8 спеки).
