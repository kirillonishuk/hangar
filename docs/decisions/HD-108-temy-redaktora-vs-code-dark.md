# HD-108 — 2026-10-29 — Темы редактора: VS Code Dark Modern, «Своя», опции редактора (заменяет выбор палитры из HD-084; спека `docs/superpowers/specs/2026-10-29-editor-theme-design.md`, макет `editor-theme.html`).

Решения владельца: (1) встроенная тема «VS Code Dark Modern» — таблицы §2 спеки (синтаксис Dark+, пунктуация и текст `#cccccc`; фон `#1f1f1f`, номера `#6e7681`/`#cccccc`, курсор `#aeafad`, текущая строка — рамка `#282828` без заливки, выделение `#264f78`/`#3a3d41`, направляющие `#404040`/`#707070`, пробелы `#e3e4e229`, найденное `#9e6a03`/`#ea5c0055`, пара скобок `#0064001a`/`#888888`, diff `#9bb95533`/`#ff000033`/`#9ccc2c33`/`#ff000033`); её цвета редактора от темы оформления не зависят, виджеты (поиск, подсказки, меню) остаются в цветах Hangar. **Тема по умолчанию:** `editor_palette` по умолчанию `dark-modern` — и для новых установок, и для конфигов без этого ключа; явно выбранная палитра (`dark-plus`, `hangar`) — запись в файле, она сохраняется. Настройки пишут `editor_palette` только при выборе, так что «никогда не выбирал» = нет ключа = Dark Modern. (2) Высота строки «авто» = `round(1,5 × размер)`, как в VS Code, по умолчанию (при 13 pt — те же 20). (3) «Своя» (`editor_palette = "custom"`): основа `editor_custom_base` (встроенная) + изменённые `editor_color_<группа>` (32 id, `#rgb`/`#rrggbb`; `#rrggbbaa` — только у цветов поверх текста: выделение, найденное, пробелы, diff — у остальных альфа в конфиге ошибка, а в поповере отбрасывается, чтобы превью совпадало с редактором; неизвестный id — `unknownKey`, плохой hex — `syntax` с номером строки). Изменение цвета во встроенной теме создаёт «Свою» на её основе; если в «Своей» есть изменения на другой основе — `ConfirmSheet` «Заменить свою тему?»; цвет, равный цвету основы, — не изменение (ключ удаляется). «Сбросить» строки и «Сбросить всё» удаляют ключи (`ConfigWriter.removing`/`remove(key:)`: только строки корневой секции, комментарии и порядок остальных строк не трогаются; несколько ключей — одна атомарная запись `save(to:edit:)`). У основ Dark+ и Hangar неизменённые цвета редактора по-прежнему идут от темы оформления. Одна таблица группа → токены Monaco для всех тем (`EditorColor.tokens`; у Hangar функции/переменные/атрибуты теперь цвета текста, `predefined` — цвет функций). (4) Опции (`EditorOptions`, ключи `editor_font_family/size/line_height/ligatures/tab_size/detect_indentation/word_wrap/line_highlight/cursor_style/cursor_blinking/whitespace/bracket_colors/bracket_guides/indent_guides/format_on_save`): умолчания — прежнее поведение Hangar (SF Mono 13, табуляция 4 с определением по файлу, «Номер и строка», «Не мигает», пробелы «В выделении», скобки и направляющие вкл.). Имя шрифта — только буквы, цифры, пробел, `-_.` (уходит в CSS-список). «Формат при сохранении»: ⌘S сначала запускает действие «Форматировать документ» (тот же запрос `format` к tsserver/LSP, только у файлов с провайдером), ждёт до 3 с, потом сохраняет; правки форматирования, пришедшие позже, отбрасываются (иначе только что сохранённый буфер снова «изменён»). Всё применяется к открытым страницам Monaco сразу (`setLook` → `defineTheme` + `updateOptions` у редактора и обеих сторон diff), без перезагрузки. (5) Раскладка — под минимальное окно настроек (680 × 440, страница 441 pt), окно не увеличивалось: плитки тем 2 × 2 (в ряд по 4 названия не помещаются), подсказка под плитками — с резервом в две строки; превью **над** списком и закреплено (`LazyVStack` с `pinnedViews`), пока список прокручивается; группы списка сворачиваются («Редактор», «Diff» свёрнуты); превью — сегмент «TypeScript / JSON / Diff» вместо «Всё» (12 строк, в низком окне меньше — до 6 на минимуме, остальное прокручивается внутри, наведённая строка списка подкручивает к своей строке; строки образцов ≤ 46 знаков); выборы шире сегмента на минимальной ширине — раскрывающиеся списки (меню Hangar), шрифт — системное меню (прокручивается при сотне шрифтов); пояснения к опциям — в тултипах. Превью нарисовано SwiftUI по статической разметке токенов (а не страницей Monaco, как в спеке §3): те же цвета и шрифт, наведение и клик по слову без моста в WebView, перерисовка на каждый кадр перетаскивания. Полосы оттенка и яркости помнят оттенок и насыщенность, пока цвет на экране сделан ими (у чёрного их не прочесть из hex): яркость до чёрного и обратно возвращает цвет. Перетаскивание по полосам меняет только превью; в конфиг и открытые редакторы уходит значение по отпусканию (системная палитра — `isContinuous = false`). Заодно: окно настроек на минимальной высоте обрезало страницу на 14 pt сверху и снизу (`minHeight` SwiftUI был равен минимуму рамки окна вместе с заголовком) — теперь задаётся только `minWidth`. **Отвергнуто:** импорт из VS Code (кнопка, поиск тем, синхронизация) — слово владельца; TextMate-токенизатор (не согласован, §7 спеки); увеличение окна настроек.
