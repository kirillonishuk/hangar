# HD-063 — 2026-10-24 — Паритет с Pane: restore, git-статус, значок в Dock, MCP только для чтения (дополняет #45).

`tasks.restore` (CLI `tasks restore --task T`, MCP `tasks_restore`) ищет только среди архивных задач и вызывает `restoreFromArchive` (#57); не разрушительно — без `yes`; ветки нет — `failed` без изменений (восстановить без worktree — только в UI, с подтверждением); таймаут CLI 120 с. `tasks.list` с `git: true` / `--git` добавляет в `TaskInfo` `changes {added, removed, files}` (как Changes инспектора: от merge-base с базой задачи, вместе с рабочим деревом; без базы — от HEAD), `dirty` (есть записи `status`) и `ahead`/`behind` (`rev-list --left-right --count base...HEAD`, без базы — нет); задачи параллельно; у показанной в инспекторе задачи берутся его загруженные changes; ошибка git (не репозиторий, хост офлайн) — просто без полей; без флага git не запускается, таймаут CLI с `--git` 60 с. Отвергнуто: одна `status --porcelain=v2 --branch` (ahead/behind там от upstream, а не от базы, и без строк). Значок в Dock: число незаархивированных задач в состоянии «ждёт» (`NSApp.dockTile.badgeLabel`, пусто при 0), пересчёт в `didSet` статусов и при смене настройки, без таймера; переход листа в «ждёт» — `requestUserAttention(.informationalRequest)`, если приложение неактивно; настройка `dock_badge` (по умолчанию вкл.) выключает и значок, и прыжок. `hangar mcp --read-only`: `tools/list` — только `projects_list`, `tasks_list`, `tabs_read` и `doctor` (`ControlMethod.readOnly`; `doctor` ничего не меняет), вызов другого инструмента — JSON-RPC ошибка -32602 «not available: … --read-only» до обращения к приложению; подсказка в настройках упоминает флаг. `--read-only` ограничивает только MCP-инструменты: агент с доступом к shell по-прежнему может запустить CLI `hangar` (сокет тот же), это не песочница. Почему: аудит Pane-паритета (п. 2, 3, 4, 10).
