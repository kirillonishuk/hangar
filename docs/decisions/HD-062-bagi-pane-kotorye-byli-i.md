# HD-062 — 2026-10-24 — Баги Pane, которые были и у Hangar (`tabs send`, `--continue`, доверие к папке).

Дополняет HD-045 и HD-041.
- `tabs send` (Pane #302/#723/#513): ответ несёт `status` и `hint`. По умолчанию `sent`, без ожидания. `--wait` (MCP `wait: true`) после Enter ждёт до 10 с, пока лист claude станет `working` (hook UserPromptSubmit): `started` или `not-started-yet` с подсказкой «проверь `tabs read`» (диалог или не установлены hooks). Ожидание — continuation, которое будит `apply` статуса или таймаут запроса, без опроса. Таймаут клиента с `--wait` — 20 с. Claude уже `working` → текст отправляется, ответ `queued` (claude ставит ввод в очередь после хода).
- Codex (Pane #945/#496): события «ход начался» у Codex нет (HD-043), поэтому занятость читается с экрана: строка «esc to interrupt» в последних 15 строках (`shortcut:`, заменить на hooks Codex). Enter в занятый codex отклоняется с кодом `busy` и подсказкой, ничего не вставляется. Клавиши без Enter проходят. Клавишу очереди Codex не используем: без установленного codex её не проверить. С `--wait` для codex ответ `sent` и подсказка, что codex начало хода не сообщает.
- `--key interrupt`: Esc для claude/codex, Ctrl-C для shell/редактора. Выбирается по виду листа в `AppState`.
- `--continue` (Pane #850/#1054): правило «только первый лист без id в (вид, папка) продолжает» (HD-041, `resumeSet`) действовало только при старте и разархивации. ↩ после выхода снова запускал `--continue`/`resume --last` и мог подхватить чужой разговор. Теперь `spec(for:)` применяет то же правило к каждому запуску agent-листа. Ключ — (вид, хост, папка без завершающего `/`): тот же путь на другом хосте или локально — другая машина и другой разговор.
- Доверие к папке (Pane #968): Hangar диалог доверия не принимает, это решение пользователя. `tasks create` с вкладкой агента возвращает `note` (в CLI — строка `note: …`): агент может спросить о доверии, ответ даёт пользователь во вкладке. Первое сообщение не теряется: оно — аргумент запуска (HD-029), а не вставка. Как claude обрабатывает аргумент после ответа на диалог, вживую не проверено: настоящий claude не запускали.
