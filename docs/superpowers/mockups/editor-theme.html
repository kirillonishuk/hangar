Тема и настройки редактора

Настройки → Редактор. Новая встроенная тема «VS Code Dark Modern» — цвета взяты из вашего VS Code один раз и зашиты в Hangar, никакой синхронизации. Любую тему можно открыть как «Своя»: нажмите на образец цвета или на слово в превью. Наведите курсор на строку цвета — в превью останутся видны только её токены.

Что меняется по сравнению с нынешним «VS Code Dark+» в Hangar

Цвета синтаксиса у Dark Modern те же, что у Dark+: тема VS Code подключает dark_plus.json и меняет только интерфейс. Разница, которую видно, — в фоне, тексте, номерах строк, курсоре, текущей строке и шрифте.
