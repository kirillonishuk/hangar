# HD-099 — 2026-10-28 — Пустая сессия после закрытия последней вкладки; ⌘Q из терминала; обновления каждый час (баги владельца в 0.4.0/0.4.1).

Сессия без вкладок (⌘W или `×` на последней, восстановление сессии без вкладок) остаётся в сайдбаре и выбранной, ничего сама не запускает; в области вкладок над панелью TERMINAL — строка «Нет вкладок» (`text3`) и кнопки «Claude», «Codex», «Терминал ⌘T» (стиль «+ Добавить проект», `FilledRowStyle`, логотипы как в меню `+`); у терминала хоста (HD-064) — только «Терминал». Кнопка — то же, что пункт меню `+` (`AppState.addTab`). Раньше там была одна строка «Нет вкладок — ⌘T или + в полосе вкладок». Кода, который сам создавал бы вкладку в пустой сессии, в 0.4.1 нет: в изолированной DEBUG-проверке ⌘W на единственной вкладке, повторный выбор сессии, перезапуск и открытая панель TERMINAL вкладку не создают (тест закрепляет это и для восстановления). ⌘Q: при фокусе в терминале клавишу забирала привязка Ghostty по умолчанию `super+q = quit` раньше меню приложения, а действие Ghostty `quit` (цель — приложение) Hangar не обрабатывает, поэтому выход не происходил; теперь монитор клавиш ловит ⌘Q по keyCode (и ⌘Й в русской раскладке) и вызывает обычный `NSApp.terminate` — с подтверждением, когда агенты работают или есть несохранённые файлы (как у ⌘,, HD-056). Обновления: см. исправленный HD-086 — проверка при каждом запуске и при активации не чаще раза в час. Настройки → Общие → «Версия»: когда найдено обновление (в том числе пропущенное — пропуск прячет только плашку), справа основная кнопка «Обновить до X.Y.Z» на месте «Проверить сейчас» (обе в строку не помещаются, а «Доступна X.Y.Z» дублировала бы кнопку); она запускает тот же путь, что «Обновить» в листе: загрузка и проверка (ход — текстом в строке, кнопки нет), затем обычный выход с подтверждением при работающих агентах и перезапуск; подготовленное обновление после отменённого выхода — «Перезапустить». Окно настроек выход не держит (`terminate` не спрашивает его `windowShouldClose`), а вопрос о выходе при активном приложении выводит главное окно вперёд, иначе лист оказался бы за настройками. Раньше ставить обновление можно было только плашкой в строке статуса, закрыв настройки. Отвергнуто: автоматически открывать вкладку агента в пустой сессии (запускает процесс без спроса), закрывать сессию вместе с последней вкладкой (это архивирование, ⌘⇧W), таймер проверки обновлений (энергия: в простое ноль таймеров).
